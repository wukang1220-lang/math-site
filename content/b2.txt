# 二元一次式
- 化簡後含有兩種文字，而且每一種文字的次方都是 1，叫做**二元一次式**，例如 4x − 3y + 1。
- 化簡時只合併**同類項**：x 項和 x 項、y 項和 y 項、常數和常數。
- 有括號先用分配律去括號；有分母**先通分**：\f{x + y}{2} − \f{x − y}{3} = \f{3(x + y) − 2(x − y)}{6} = \f{x + 5y}{6}。
# 二元一次方程式
- 含有兩個未知數、未知數的次方都是 1 的等式，叫做**二元一次方程式**，例如 2x + y = 7。
- 能使等式成立的一組數 (x, y)，叫做它的一組**解**。
- 沒有其他條件時，一個二元一次方程式有**無限多組解**。
- 加上「x、y 為正整數」之類的條件，解就可能**只有幾組**。例：2x + y = 7 的正整數解有 (1, 5)、(2, 3)、(3, 1)。
! 已知一組解，把它代入方程式，可以求出式子中未知的係數。
EX: 若 x = 2、y = −1 是 3x + ay = 10 的解，求 a。
=> 代入：3 × 2 + a × (−1) = 10，6 − a = 10
=> a = −4
Q: 下列哪一個是二元一次方程式？
o*: 3x − 2y = 5
o: x^2 + y = 4
o: 2x + 5
o: xy = 6
E: 3x − 2y = 5 有兩個未知數且次方都是 1。x^2 是二次；2x + 5 沒有等號，不是方程式；xy 是二次項。
Q: 化簡 3(2x − y) − 2(x − 4y) 的結果是什麼？
o*: 4x + 5y
o: 4x − 11y
o: 4x − 5y
o: 8x + 5y
E: 6x − 3y − 2x + 8y = 4x + 5y。注意 −2 × (−4y) = +8y。
Q: x + 2y = 9 的正整數解共有幾組？
o: 2

o*: 4
o: 5
E: y = 1、2、3、4 時，x = 7、5、3、1，共 4 組；y = 5 時 x = −1 不是正整數。
Q: 若 (x, y) = (−1, 3) 是 ax + 2y = 10 的一組解，則 a 是多少？
o*: −4
o: 4
o: 16
o: −16
E: −a + 6 = 10，a = −4。

# 聯立方程式與它的解
- 兩個二元一次方程式寫在一起，叫做**二元一次聯立方程式**，例如 \sys{x + y = 5}{x − y = 1}。
- 能同時使兩個方程式成立的一組 (x, y)，就是聯立方程式的**解**。
# 代入消去法
- 把其中一式改寫成 y = …（或 x = …），**代入另一式**，消去一個未知數。
- 適合某個未知數的**係數是 1 或 −1** 的時候。
# 加減消去法
- 把兩式乘上適當的數，讓某個未知數的**係數相同或互為相反數**。
- 係數相同就兩式**相減**，係數互為相反數就兩式**相加**，消去它。
! 係數有分數或小數時，先乘上適當的數化成整數係數再解。
# 特殊形式
- **A = B = C** 的形式：拆成 \sys{A = B}{B = C} 或 \sys{A = C}{B = C} 再解。
- 若 |A| + |B| = 0 或 A^2 + B^2 = 0，則 **A = 0 且 B = 0**，列成聯立方程式。
EX: 解 \sys{3x + 2y = 4}{5x − 2y = 12}。
=> y 的係數互為相反數，兩式相加：8x = 16，x = 2。
=> 代回第一式：6 + 2y = 4，y = −1，解為 (2, −1)。

# 解題步驟
- 找出**兩個未知量**，分別設為 x、y（寫清楚單位）。
- 從題目找出**兩個**相等關係，列成聯立方程式。
- 解出後驗算，並檢查是否**符合題意**，例如人數、張數要是正整數。
! 題目給了兩種方案或兩種情況時，通常就對應兩個方程式。
# 常見類型
- 買賣：分別用**「數量」與「總價」**各列一式。
- 數字問題：兩位數 = **10 × 十位數字 + 個位數字**。
- 雞兔、票價：「隻數（張數）和」與「腳數（總價）和」**各列一式**。
- 行船：順流速率 = **船速 + 水速**，逆流速率 = 船速 − 水速。
EX: 2 杯奶茶加 3 個麵包共 145 元，1 杯奶茶加 2 個麵包共 85 元。奶茶與麵包各多少元？
=> 設奶茶 x 元、麵包 y 元：\sys{2x + 3y = 145}{x + 2y = 85}
=> 第二式乘 2 再減去第一式：y = 25，代回得 x = 35。

o: 74
o: 38
o: 56
E: 設十位 a、個位 b：a + b = 11，(10b + a) − (10a + b) = 27，得 b − a = 3，所以 a = 4、b = 7。

# 坐標平面
- 兩條互相垂直、交於原點 O 的數線，構成**直角坐標平面**。
- 水平的叫 **x 軸（橫軸）**，向右為正；鉛直的叫 y 軸（縱軸），向上為正。
# 點的坐標
- 點 P 的位置用數對 (a, b) 表示，a 是 **x 坐標**，b 是 **y 坐標**，記作 P(a, b)。
- 原點是 (0, 0)；**x 軸上的點是 (a, 0)**；y 軸上的點是 (0, b)。
- 若 (a, b) 與 (c, d) 是同一點，則 **a = c 且 b = d**。
# 點到兩軸的距離
- P(a, b) 到 **x 軸**的距離是 |b|，到 **y 軸**的距離是 |a|。
! 「到 x 軸的距離」看的是 y 坐標，兩者很容易弄反。
# 象限
- 兩軸把平面分成四個**象限**，從右上開始逆時針依序是第一、二、三、四象限。
- 坐標符號：**第一 (＋, ＋)、第二 (−, ＋)、第三 (−, −)、第四 (＋, −)**。
- 坐標軸上的點**不屬於任何象限**。
# 點的平移
- 向右平移 s 單位：**(a + s, b)**；向左：(a − s, b)。
- 向上平移 t 單位：**(a, b + t)**；向下：(a, b − t)。
- 同一條水平線上兩點的距離 = **x 坐標相減的絕對值**；同一條鉛直線上看 y 坐標。
EX: 點 A(−3, 5) 先向右移 7 單位，再向下移 8 單位得到點 B。B 在第幾象限？
=> B(−3 + 7, 5 − 8) = B(4, −3)
=> x 坐標為正、y 坐標為負，在第四象限。
Q: 點 P(−4, 7) 到 x 軸的距離是多少？
o: −4
o: 4
o*: 7
o: 11
E: 到 x 軸的距離看 y 坐標：|7| = 7。
Q: 若 a > 0、b < 0，點 (−a, b) 在第幾象限？
o*: 第三象限
o: 第一象限
o: 第二象限
o: 第四象限
E: −a < 0，b < 0，坐標符號 (−, −)，在第三象限。
Q: 已知點 (2m − 6, m + 1) 在 y 軸上，m 是多少？
o: −3
o: −1
o*: 3
o: 6
E: y 軸上的點 x 坐標為 0：2m − 6 = 0，m = 3。
Q: A(−2, 3)、B(5, 3) 兩點的距離是多少？
o: 3
o: 6
o*: 7
o: 10
E: 兩點 y 坐標相同，在同一條水平線上，距離 = |5 − (−2)| = 7。

# 圖形是一條直線
- 把方程式 ax + by = c 的每一組解畫成點，所有的點連起來是一條**直線**，就是它的圖形。
- 畫圖只要找出**兩組解**（常令 x = 0、y = 0），描點後連成直線即可。
- 點 (x_1, y_1) 在 ax + by = c 的圖形上，表示 **a x_1 + b y_1 = c**。
# 三種直線
- y = k（k 為常數）：**水平線**，與 x 軸平行；x 軸的方程式是 y = 0。
- x = h（h 為常數）：**鉛垂線**，與 y 軸平行；y 軸的方程式是 x = 0。
- 其他的 ax + by = c（a、b 都不為 0）：**斜直線**，可寫成 y = mx + k 的形式。
# 已知兩點求直線
- 兩點 y 坐標相同：**水平線 y = k**；x 坐標相同：鉛垂線 x = h。
- 都不相同：**設 y = ax + b**，把兩點代入，解聯立方程式求 a、b。
# 聯立方程式的圖形
- 兩條直線的**交點坐標**就是聯立方程式的解。
- 兩直線交於一點，聯立方程式**恰有一組解**。
EX: 求通過 (1, 3) 與 (3, 7) 的直線方程式。
=> 設 y = ax + b，代入：\sys{a + b = 3}{3a + b = 7}
=> 相減得 a = 2，b = 1，直線為 y = 2x + 1。
Q: 通過點 (−2, 5) 且與 x 軸平行的直線是哪一條？
o*: y = 5
o: x = −2
o: y = −2
o: x = 5
E: 與 x 軸平行是水平線，線上每一點的 y 坐標都是 5。
Q: 直線 3x − 2y = 12 與 x 軸的交點坐標是什麼？
o*: (4, 0)
o: (0, −6)
o: (0, 4)
o: (−6, 0)
E: x 軸上 y = 0：3x = 12，x = 4，交點 (4, 0)。(0, −6) 是與 y 軸的交點。
Q: 點 (k, 2) 在直線 2x + 3y = 4 上，k 是多少？
o*: −1
o: 1
o: 5
o: −5
E: 代入：2k + 6 = 4，k = −1。
Q: 直線 x + y = 4 與 x − y = 2 的交點是哪一點？
o*: (3, 1)
o: (1, 3)
o: (2, 2)
o: (4, 2)
E: 兩式相加 2x = 6，x = 3，y = 1。交點就是聯立方程式的解。

# 比與比值
- 兩數 a、b（b ≠ 0）的比記作 a : b，a 是**前項**、b 是後項；比值是 \f{a}{b}。
- **後項不可以是 0**，前項可以是 0。
- 同類的量才能比，**單位要先統一**：30 分鐘 : 2 小時 = 30 : 120 = 1 : 4。
# 相等的比與最簡整數比
- 比值相等的兩個比叫做**相等的比**，例如 6 : 8 = 9 : 12（比值都是 \f{3}{4}）。
- 前項、後項同乘或同除一個不為 0 的數，**比值不變**。
- 前後項都是整數而且互質，叫做**最簡整數比**；有分數時先同乘分母的最小公倍數：\f{1}{2} : \f{2}{3} = 3 : 4。
# 比例式
- 兩個相等的比寫成 a : b = c : d，叫做**比例式**；a、d 是外項，b、c 是內項。
- **外項乘積 = 內項乘積**：a : b = c : d 時，ad = bc。
- 若 x : y = a : b，可以設 **x = ar、y = br**（r ≠ 0）。
! 由 ax = by（a、b ≠ 0）可得 x : y = b : a，左右要交叉對應。
# 按比例分配
- x : y = a : b 且 x + y = k 時，**x = k × \f{a}{a + b}**，y = k × \f{b}{a + b}。
- 例：120 按 3 : 5 分，分別是 120 × \f{3}{8} = 45 和 120 × \f{5}{8} = 75。
EX: 已知 (x + 2) : 3 = (x − 1) : 2，求 x。
=> 外項乘積 = 內項乘積：2(x + 2) = 3(x − 1)
=> 2x + 4 = 3x − 3，x = 7
Q: 0.6 : 1\f{1}{2} 化成最簡整數比是多少？
o*: 2 : 5
o: 5 : 2
o: 3 : 5
o: 6 : 15
E: 0.6 : 1.5 = 6 : 15 = 2 : 5。6 : 15 還可以再約分。
Q: 若 3x = 5y（x、y 都不為 0），則 x : y 是多少？
o*: 5 : 3
o: 3 : 5
o: 15 : 1
o: 1 : 15
E: 兩邊同除以 3y：\f{x}{y} = \f{5}{3}，所以 x : y = 5 : 3。
Q: 甲、乙兩人按 4 : 5 分 3600 元，乙分得多少元？
o: 1600
o: 1800
o*: 2000
o: 2250
E: 乙 = 3600 × \f{5}{9} = 2000。
Q: 若 x : 6 = 10 : 4，則 x 是多少？
o: 2.4
o: 12
o*: 15
o: 20
E: 外項乘積 = 內項乘積：4x = 60，x = 15。

# 正比
- x 變化時 y 也跟著變，而且 y 一直是 x 的 k 倍（k ≠ 0），即 y = kx，就說 y 與 x 成**正比**。
- 也可以說**比值 \f{y}{x} = k** 固定不變。
- 求值：**設 y = kx**，用一組已知的 x、y 求出 k，再求所要的值。
- 成正比時，**y_1 : y_2 = x_1 : x_2**。
# 反比
- x 與 y 的**乘積固定**，xy = k（k ≠ 0），就說 y 與 x 成**反比**，也可寫成 y = \f{k}{x}。
- 求值：**設 xy = k**，用一組已知的 x、y 求出 k。
- 成反比時，**x_1 y_1 = x_2 y_2**，也就是 y_1 : y_2 = x_2 : x_1。
! x + y = k（k ≠ 0）時，x 與 y 既不成正比，也不成反比。
# 生活中的例子
- 單價固定時，總價與數量**成正比**。
- 路程固定時，速率與所需時間**成反比**。
- 工作總量固定、每人效率相同時，人數與完成天數**成反比**。
EX: y 與 x 成反比，x = 4 時 y = 9，求 x = 6 時的 y。
=> xy = 4 × 9 = 36
=> x = 6 時，y = 36 ÷ 6 = 6
Q: y 與 x 成正比，x = 3 時 y = 12。x = 5 時 y 是多少？
o: 7.2
o: 15

o: 60
E: k = 12 ÷ 3 = 4，y = 4 × 5 = 20。

o: 每枝 15 元的鉛筆買 x 枝，共 y 元
o: 正方形的邊長是 x，周長是 y
o: 兩數的和是 10，一數是 x、另一數是 y
E: 長 × 寬 = 24，乘積是固定且不為 0 的數，所以成反比。鉛筆、周長都是正比；和固定兩者都不是。

# 不等式
- 含有 >、<、≥、≤、≠ 的式子叫做**不等式**。
- 只含一個未知數，而且未知數的次方是 1 的不等式，叫做**一元一次不等式**，例如 3x − 1 > 8。
# 文字與不等號
- 大於、超過、多於、高於 → >；小於、不足、**未滿**、少於 → <。
- **至少**、不小於、不低於、以上（含）→ ≥；**至多**、不大於、不超過、以下（含）→ ≤。
# 不等式的解與圖示
- 代入後能使不等式成立的數，都是它的**解**；一元一次不等式通常有無限多個解。
- 在數線上畫解：包含端點用**實心點**，不含端點用**空心點**，再往左或往右畫線。
- 例：x ≥ 2 在 2 畫實心點、往右；x < −1 在 −1 畫空心點、往左；−1 < x ≤ 3 畫兩端點之間。
# 運算性質
- 兩邊同加或同減一個數，不等號**方向不變**。
- 兩邊同乘或同除一個**正數**，方向不變。
- 兩邊同乘或同除一個**負數**，方向要**改變**：若 a > b，則 −2a < −2b。
EX: 用不等式表示「x 的 3 倍減 4 不超過 11」，並求出 x 的範圍。
=> 不超過就是 ≤：3x − 4 ≤ 11
=> 3x ≤ 15，x ≤ 5
Q: 「某數 x 的 2 倍再加 5，至少是 17」寫成不等式是哪一個？
o*: 2x + 5 ≥ 17
o: 2x + 5 > 17
o: 2x + 5 ≤ 17
o: 2(x + 5) ≥ 17
E: 「至少」包含等於，用 ≥；「2 倍再加 5」是 2x + 5。

# 解不等式的步驟
- 去分母、去括號 → 移項（未知數放一邊）→ 合併成 ax > b → **兩邊同除以 a**。
- a 是負數時，除完要**改變不等號方向**。例：−3x ≥ 12，得 x ≤ −4。
- 移項的規則**和方程式一樣**：＋ 變 −、− 變 ＋。
# 同時滿足兩個不等式
- 分別解出兩個不等式，畫在同一條數線上，取**重疊**的部分。
- 例：x > −1 且 x ≤ 4，就是 −1 < x ≤ 4，其中的整數有 0、1、2、3、4。
# 應用題
- 圈出「至少、最多、不超過、超過」等**關鍵字**，決定用哪一個不等號。
- 算出範圍後要回到題意：人數、件數要取**整數**；問「至少」取範圍內最小的整數，問「最多」取最大的整數。
- 注意題目沒寫出的條件：長度、價格、數量**都要大於 0**。
! 比較兩種方案時，分別寫出兩種方案的費用，列成「方案甲 < 方案乙」再解。
EX: 某飲料店每杯 45 元，買 6 杯以上每杯打 8 折。小宇帶 500 元要買 6 杯以上，最多能買幾杯？
=> 設買 x 杯：45 × 0.8 × x ≤ 500，36x ≤ 500
=> x ≤ 13.8…，杯數取整數，最多買 13 杯。

# 列聯表與次數分配表
- 依兩種以上的類別分組統計，做成**列聯表**，可以同時比較兩種分類。
- 把資料分組並統計每組的個數（次數），做成**次數分配表**；每組的範圍大小叫做組距。
- 分組「a ~ b」表示 a 以上（含 a）、**未滿 b**；最後一組通常包含上限。
# 常見統計圖
- **長條圖**：比較各類別數量的多少。
- **折線圖**：看資料隨時間變化的趨勢。
- 圓形圖：看各部分占全體的比例，扇形圓心角 = **百分率 × 360°**。
- **直方圖**：分組資料的次數，長方形一個接一個、沒有間隔，寬是組距、高是次數。
- 次數分配折線圖：以各組的**組中點**為橫坐標、次數為縱坐標描點連線。
! 讀圖先看縱軸的單位與起點；縱軸若不是從 0 開始，長條高度的比例會誤導人。
# 平均數、中位數、眾數
- **算術平均數** = 資料總和 ÷ 資料個數。
- **中位數**：資料由小到大排好，正中間的數；個數是偶數時，取中間兩數的平均。
- **眾數**：出現次數最多的數，可能不只一個。
- 有特別大或特別小的極端值時，**中位數比平均數更能代表一般情形**。
EX: 7 位同學的跳繩次數：40、45、45、50、56、60、68，求平均數、中位數、眾數。
=> 平均數 = 364 ÷ 7 = 52
=> 第 4 個數是 50，中位數 50；45 出現 2 次，眾數 45。

# 點、線、角
- 直線向兩端無限延伸，**射線只向一端延伸**，線段有兩個端點；線段 AB 的長度記作 \seg{AB}。
- 角記作 ∠ABC（**頂點寫在中間**），也可以寫成 ∠B 或 ∠1。
- 多邊形的頂點依順時針或逆時針順序讀；不相鄰兩頂點的連線叫做**對角線**。
- 每邊等長、每個內角也相等的多邊形，叫做**正多邊形**。
# 垂直與距離
- 兩直線相交成 90°，叫做**互相垂直**，記作 L ⊥ M，交點叫做垂足。
- 點 P 到直線 M 的垂直線段長，是 P 到 M 的**距離**，也是 P 到 M 上各點的最短距離。
# 中點、中垂線、角平分線
- M 在 \seg{AB} 上且 \seg{AM} = \seg{BM}，M 是 \seg{AB} 的**中點**。
- 通過線段中點並與線段垂直的直線，叫做**垂直平分線**（中垂線）。
- 把一個角分成兩個相等角的射線，叫做**角平分線**。
# 線對稱圖形
- 沿一條直線對摺後兩邊完全重合的圖形，叫做**線對稱圖形**，這條直線叫做**對稱軸**。
- 對稱點的連線被對稱軸**垂直平分**；對稱的線段等長、對稱的角相等。
- 對稱軸的數量：等腰三角形 1、箏形 1、菱形 2、長方形 2、正方形 4、**正 n 邊形 n 條**，圓有無限多條。
! 長方形的對角線**不是**對稱軸；菱形的對角線才是。
# 三視圖
- 從前方、上方、右方看立體圖形畫出的平面圖，叫做**前視圖**、上視圖、右視圖。
- 前視圖與後視圖**左右相反**；左視圖與右視圖也左右相反。
- 上視圖可以看出**底層的排列**，再用前視圖、右視圖推算每個位置疊幾個積木。
EX: 一個線對稱圖形中，A 與 A′ 是對稱點，\seg{AA′} = 10，對稱軸 L 與 \seg{AA′} 交於 M。求 \seg{AM}。
=> 對稱軸垂直平分對稱點的連線，所以 M 是 \seg{AA′} 的中點。
=> \seg{AM} = 10 ÷ 2 = 5
