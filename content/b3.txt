# 和的平方
- **(a + b)^2 = a^2 + 2ab + b^2**。
- 例：103^2 = (100 + 3)^2 = 10000 + 600 + 9 = 10609。
! (a + b)^2 不等於 a^2 + b^2，中間的 2ab 不能漏掉。
# 差的平方
- **(a − b)^2 = a^2 − 2ab + b^2**。
- 例：98^2 = (100 − 2)^2 = 10000 − 400 + 4 = 9604。
# 平方差
- **(a + b)(a − b) = a^2 − b^2**。
- 例：52 × 48 = (50 + 2)(50 − 2) = 2500 − 4 = 2496。
# 圖形的意義
- 邊長 a + b 的正方形，可以切成 a^2、b^2 和**兩個 ab 長方形**，所以面積 = a^2 + 2ab + b^2。
- 乘法公式可以做速算，也是之後**因式分解的基礎**。
- 常用變形：**a^2 + b^2 = (a + b)^2 − 2ab**，(a − b)^2 = (a + b)^2 − 4ab。
EX: 計算 1002^2 − 998^2。
=> 用平方差：(1002 + 998)(1002 − 998)
=> = 2000 × 4 = 8000

# 多項式的名詞
- 由數字與文字的乘積組成的式子叫做**單項式**，例如 −3x^2；幾個單項式相加叫做**多項式**。
- 每一個單項式叫做「項」；不含文字的項叫做**常數項**；文字前面的數字叫做**係數**。
- 次數最高的項的次數，就是多項式的**次數**：3x^2 − x + 5 是二次多項式。
- 不為 0 的常數是**零次多項式**；0 叫做零多項式。
# 降冪與升冪
- 依次數由高到低排列叫做**降冪排列**，由低到高叫做升冪排列。
- 例：5 − 2x + x^3 降冪排列成 x^3 − 2x + 5（缺 x^2 項，係數看成 0）。
# 加法與減法
- 只有**同類項**（文字與次數都相同）才能合併，把係數相加減。
- 減去一個多項式，括號內**每一項都要變號**。
- 也可以把同次項上下對齊，用直式計算；**缺項要補 0**。
EX: 計算 (3x^2 − 5x + 2) − (x^2 + 2x − 7)。
=> = 3x^2 − 5x + 2 − x^2 − 2x + 7
=> = 2x^2 − 7x + 9

E: 最高次項是 −3x^3，所以是三次；不含 x 的項是 4。

# 乘法
- 單項式相乘：係數相乘，同一文字的**指數相加**，例 (−2x^2)(3x^3) = −6x^5。
- 多項式相乘：用分配律讓**每一項都乘到**，再合併同類項。
- 例：(2x + 1)(x − 3) = 2x^2 − 6x + x − 3 = 2x^2 − 5x − 3。
# 除法
- 單項式相除：係數相除，**指數相減**，例 12x^5 ÷ 4x^2 = 3x^3。
- 多項式除以多項式用長除法；被除式和除式都要**降冪排列，缺項補 0**。
- 被除式 = 除式 × 商式 + 餘式，而且餘式的次數要**小於**除式的次數。
- 餘式為 0 叫做**整除**，這時除式是被除式的因式。
! 檢查：把「除式 × 商式 + 餘式」乘回去，看是否等於被除式。
EX: 計算 (2x^2 + x − 7) ÷ (x + 2)。
=> 2x^2 ÷ x = 2x，2x(x + 2) = 2x^2 + 4x，相減得 −3x − 7。
=> −3x ÷ x = −3，−3(x + 2) = −3x − 6，相減得 −1。
=> 商式 2x − 3，餘式 −1。

# 平方根
- 若 x^2 = a（a ≥ 0），x 叫做 a 的**平方根**（二次方根）。
- 正數有**兩個平方根**，互為相反數：正的記作 \r{a}，負的記作 −\r{a}。例：9 的平方根是 ±3。
- 0 的平方根只有 0；**負數沒有平方根**。
- **\r{a^2} = |a|**，例如 \r{(−5)^2} = 5。
# 近似值
- 若 n^2 < a < (n + 1)^2，則 **n < \r{a} < n + 1**。例：49 < 50 < 64，所以 7 < \r{50} < 8。
- 常用近似值：**\r{2} ≈ 1.414**，\r{3} ≈ 1.732，\r{5} ≈ 2.236。
- a、b 為正數時，a > b 就有 **\r{a} > \r{b}**。
# 有理數與無理數
- 能寫成 \f{整數}{不為 0 的整數} 的數叫做**有理數**，包含整數、有限小數、循環小數。
- 無法寫成分數、是不循環無限小數的數叫做**無理數**，例如 \r{2}、\r{3}、π。
- 有理數與無理數合稱**實數**，每個實數都對應數線上的一個點。
! \r{16} = 4 是有理數，判斷前先看根號能不能開得盡。
EX: \r{90} 介於哪兩個連續整數之間？
=> 9^2 = 81，10^2 = 100，81 < 90 < 100
=> 所以 9 < \r{90} < 10

o: −7
o: 24.5
E: 7^2 = 49，(−7)^2 = 49，正數有兩個平方根。

o*: 6
o: −6

o: 36
E: \r{(−6)^2} = \r{36} = 6，根號的值不會是負的。

# 最簡根式
- 根號內沒有開得盡的因數（4、9、25、…），也沒有分母，叫做**最簡根式**。
- 化簡：\r{72} = \r{36 × 2} = **6\r{2}**；\r{\f{3}{4}} = \f{\r{3}}{2}。
# 乘法與除法
- **\r{a} × \r{b} = \r{ab}**，\r{a} ÷ \r{b} = \r{\f{a}{b}}（a ≥ 0，b > 0）。
- 例：\r{6} × \r{15} = \r{90} = 3\r{10}。
# 分母有理化
- 分母有根號時，分子分母同乘一個根式，讓**分母變成整數**：\f{6}{\r{3}} = \f{6\r{3}}{3} = 2\r{3}。
- 分母是 \r{a} + \r{b} 時，分子分母**同乘 \r{a} − \r{b}**（平方差）：\f{1}{\r{3} + \r{2}} = \r{3} − \r{2}。
# 加法與減法
- 化成最簡根式後，根號內相同的**同類方根**才能合併：2\r{3} + 5\r{3} = 7\r{3}。
- **\r{a} + \r{b} ≠ \r{a + b}**：\r{9} + \r{16} = 7，但 \r{25} = 5。
! 先把每一項化成最簡根式，再找同類方根合併。

=> \r{48} = 4\r{3}，\r{27} = 3\r{3}，\r{12} = 2\r{3}

# 畢氏定理
- 直角三角形中，兩股的平方和等於斜邊的平方：**a^2 + b^2 = c^2**（c 為斜邊）。
- 斜邊是直角所對的邊，也是三邊中**最長的邊**。
- 常見的整數邊長：**3、4、5；5、12、13**；8、15、17；7、24、25（以及它們的倍數）。
# 逆敘述：判斷直角三角形
- 三角形三邊若滿足 a^2 + b^2 = c^2，則 **c 所對的角是直角**。
- 判斷時，比較「兩短邊的平方和」與**「最長邊的平方」**是否相等。
# 坐標平面上兩點的距離
- A(x_1, y_1)、B(x_2, y_2) 的距離：**\seg{AB} = \r{(x_1 − x_2)^2 + (y_1 − y_2)^2}**。
- 例：A(1, 2)、B(4, 6)，\seg{AB} = \r{3^2 + 4^2} = 5。
# 常見應用
- 正方形邊長 a，對角線長 **\r{2}a**；長方形長 a、寬 b，對角線長 \r{a^2 + b^2}。
- 正三角形邊長 a，**高 = \f{\r{3}}{2}a**，面積 = \f{\r{3}}{4}a^2。
- 梯子靠牆、走捷徑、立體中的距離：先找出**隱藏的直角三角形**。
EX: 長方形的長 12、寬 5，對角線多長？
=> 對角線把長方形分成兩個直角三角形
=> 對角線 = \r{12^2 + 5^2} = \r{169} = 13

# 因式與倍式
- 若多項式 A = B × C，則 B、C 都是 A 的**因式**，A 是 B、C 的倍式。
- 把一個多項式寫成幾個多項式的乘積，叫做**因式分解**。
- 因式分解和乘法**互為逆運算**，乘開就能檢查分解是否正確。
# 提出公因式
- 每一項都有的因式叫做**公因式**，先把它提出來：6x^2 − 9x = 3x(2x − 3)。
- 公因式也可以是**多項式**：a(x − 2) + b(x − 2) = (x − 2)(a + b)。
- **分組分解**：ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)。
! 首項是負的時候，通常連負號一起提出：−4x^2 + 8x = −4x(x − 2)。
# 利用乘法公式
- **a^2 + 2ab + b^2 = (a + b)^2**；a^2 − 2ab + b^2 = (a − b)^2。
- **a^2 − b^2 = (a + b)(a − b)**，例 9x^2 − 25 = (3x + 5)(3x − 5)。
- **先提公因式**，再看剩下的能不能用公式：2x^2 − 18 = 2(x^2 − 9) = 2(x + 3)(x − 3)。
! 要分解到每個因式都不能再分解為止。
EX: 因式分解 x^2 − 10x + 25 與 4x^2 − 49。
=> x^2 − 10x + 25 = x^2 − 2 × x × 5 + 5^2 = (x − 5)^2
=> 4x^2 − 49 = (2x)^2 − 7^2 = (2x + 7)(2x − 7)
Q: 將 12x^2 − 8x 提出最大公因式後，結果是什麼？
o*: 4x(3x − 2)
o: 4(3x^2 − 2x)
o: 2x(6x − 4)
o: x(12x − 8)
E: 公因式是 4x；其他選項括號內還有公因式可以再提出來。
Q: 下列哪一個是 x^2 − 16 的因式？
o*: x + 4
o: x − 8
o: x + 16
o: x − 2
E: x^2 − 16 = (x + 4)(x − 4)。
Q: 9x^2 + 12x + 4 因式分解的結果是什麼？

o: (3x − 2)^2
o: (9x + 2)(x + 2)

# 想法
- 十字交乘法用來分解**二次三項式** ax^2 + bx + c（a、b、c 為整數）。
- 把 a 拆成 p × r、c 拆成 q × s，若交叉相乘的和 **ps + qr = b**，則 ax^2 + bx + c = (px + q)(rx + s)。
# x^2 + bx + c
- 找兩個數，**乘積是 c、和是 b**：x^2 + 7x + 12，3 × 4 = 12、3 + 4 = 7，得 (x + 3)(x + 4)。
- c > 0：**兩數同號**，與 b 同號；c < 0：**兩數異號**，絕對值大的與 b 同號。
- 例：x^2 − 2x − 15 = (x − 5)(x + 3)。
# ax^2 + bx + c
- 例：2x^2 + 5x − 3，2 = 2 × 1，−3 = (−1) × 3，交叉相乘 2 × 3 + (−1) × 1 = 5，得 (2x − 1)(x + 3)。
- 有公因式**先提出來**：3x^2 − 6x − 9 = 3(x^2 − 2x − 3) = 3(x − 3)(x + 1)。
! 分解後把括號乘開，檢查中間項是否正確。
# 不能分解的情形
- 找不到符合的整數組合時，這個式子在整數範圍內**不能分解**，例如 x^2 + x + 1。
EX: 因式分解 3x^2 − 10x + 8。
=> 3 = 3 × 1，8 = (−4) × (−2)
=> 交叉相乘：3 × (−2) + (−4) × 1 = −10，所以 = (3x − 4)(x − 2)

o: (x − 7)(x + 2)
o: (x + 14)(x − 1)
o: (x − 7)(x − 2)
E: 7 × (−2) = −14，7 + (−2) = 5。

o*: (2x + 3)(x − 2)
o: (2x − 3)(x + 2)
o: (2x − 2)(x + 3)
o: (2x + 1)(x − 6)
E: (2x + 3)(x − 2) = 2x^2 − 4x + 3x − 6 = 2x^2 − x − 6。(2x − 3)(x + 2) 乘開是 2x^2 + x − 6。

# 一元二次方程式
- 化簡後只含一個未知數，而且最高次方是 2 的方程式，叫做**一元二次方程式**，一般式為 ax^2 + bx + c = 0（a ≠ 0）。
- 使方程式成立的數叫做它的**解（根）**。
# 因式分解法
- 依據：若 A × B = 0，則 **A = 0 或 B = 0**。
- 步驟：移項使右邊為 0 → 左邊因式分解 → **令每個因式等於 0**。
- 例：x^2 − x − 12 = 0 → (x − 4)(x + 3) = 0 → x = 4 或 x = −3。
- 若分解成 (x − a)^2 = 0，x = a 是**重根**（兩根相等）。
! 不可以兩邊同除以含 x 的式子：x^2 = 3x 若除以 x 會漏掉 x = 0，應移項成 x(x − 3) = 0。
# 由兩根寫出方程式
- 兩根為 m、n 的方程式可以寫成 **(x − m)(x − n) = 0**。
- 例：兩根為 2、−5，方程式為 (x − 2)(x + 5) = 0，即 x^2 + 3x − 10 = 0。
EX: 解 2x^2 = 5x + 3。
=> 移項：2x^2 − 5x − 3 = 0
=> (2x + 1)(x − 3) = 0，x = −\f{1}{2} 或 x = 3
Q: x^2 − 7x + 10 = 0 的解是什麼？
o*: x = 2 或 x = 5
o: x = −2 或 x = −5
o: x = 1 或 x = 10
o: x = −1 或 x = −10
E: (x − 2)(x − 5) = 0，所以 x = 2 或 x = 5。
Q: 方程式 x^2 = 6x 的解是什麼？
o*: x = 0 或 x = 6
o: x = 6
o: x = 0
o: x = ±\r{6}
E: 移項 x^2 − 6x = 0，x(x − 6) = 0，兩個解都要寫；直接除以 x 會漏掉 0。
Q: 若 x = 3 是 x^2 + kx − 6 = 0 的一個根，另一個根是多少？
o: −3
o*: −2
o: 1
o: 2
E: 代入：9 + 3k − 6 = 0，k = −1；x^2 − x − 6 = (x − 3)(x + 2) = 0，另一根為 −2。
Q: (x − 4)^2 = 0 的解是什麼？
o*: x = 4（重根）
o: x = ±4
o: x = −4
o: x = 16
E: x − 4 = 0，x = 4，兩根相等，是重根。

# 平方根法
- x^2 = k（k ≥ 0）時 **x = ±\r{k}**；(x + m)^2 = k 時 x = −m ± \r{k}。
- k < 0 時**無解**。
# 配方法
- 把 x^2 + bx 加上 **(\f{b}{2})^2**，配成完全平方：x^2 + bx + (\f{b}{2})^2 = (x + \f{b}{2})^2。
- 例：x^2 + 6x − 1 = 0 → x^2 + 6x + 9 = 1 + 9 → (x + 3)^2 = 10 → x = −3 ± \r{10}。
- x^2 的係數不是 1 時，先把兩邊**同除以它**。
# 公式解
- ax^2 + bx + c = 0（a ≠ 0）的解：**x = \f{−b ± \r{b^2 − 4ac}}{2a}**。
- **判別式** b^2 − 4ac：大於 0 有兩相異根；等於 0 有重根；小於 0 無解。
! 用公式前先整理成 ax^2 + bx + c = 0，並注意 b、c 的正負號。
EX: 用公式解 x^2 − 4x + 1 = 0。
=> a = 1、b = −4、c = 1，判別式 = 16 − 4 = 12
=> x = \f{4 ± \r{12}}{2} = \f{4 ± 2\r{3}}{2} = 2 ± \r{3}
Q: (x − 2)^2 = 9 的解是什麼？
o*: x = 5 或 x = −1
o: x = 5
o: x = 11 或 x = −7
o: x = ±3
E: x − 2 = ±3，x = 5 或 x = −1。
Q: 方程式 2x^2 + 3x + 5 = 0 的根是哪一種情形？
o*: 無解
o: 兩相異根
o: 重根
o: 兩個正根
E: 判別式 = 3^2 − 4 × 2 × 5 = 9 − 40 = −31 < 0，無解。
Q: 把 x^2 − 8x + 3 = 0 配方成 (x − p)^2 = q，q 是多少？
o: −13
o*: 13
o: 16
o: 19
E: x^2 − 8x + 16 = −3 + 16，(x − 4)^2 = 13。
Q: 3x^2 − 2x − 2 = 0 的解是什麼？
o*: x = \f{1 ± \r{7}}{3}
o: x = \f{2 ± \r{7}}{3}
o: x = \f{−1 ± \r{7}}{3}
o: x = \f{1 ± \r{7}}{6}
E: x = \f{2 ± \r{4 + 24}}{6} = \f{2 ± 2\r{7}}{6} = \f{1 ± \r{7}}{3}。

# 解題步驟
- 設未知數 → 依題意列出**一元二次方程式** → 解方程式。
- 解出兩個根後要**驗根**：長度、時間要是正數，人數要是正整數，不合的根要捨去。
# 常見類型
- 面積：長方形面積 = **長 × 寬**，常問邊長增減後的變化。
- 數字：連續整數 **n、n + 1**；連續奇數或偶數 n、n + 2。
- 道路與花圃：長方形土地中開路，可以把路**「移到邊上」**再計算剩下的面積。
- 成長率：每次成長 r，兩次後變成 **原數 × (1 + r)^2**。
EX: 長方形的長比寬多 3 公分，面積 40 平方公分，寬是多少？
=> 設寬 x 公分：x(x + 3) = 40，x^2 + 3x − 40 = 0
=> (x + 8)(x − 5) = 0，x = 5 或 −8（負數不合），寬 5 公分。
Q: 兩個連續正整數的乘積是 156，較小的數是多少？
o: 11
o*: 12
o: 13
o: 14
E: n(n + 1) = 156，n^2 + n − 156 = 0，(n + 13)(n − 12) = 0，n = 12（−13 不合）。
Q: 某商品連續兩次以相同百分率漲價，由 100 元漲到 121 元，每次漲幾 %？
o*: 10%
o: 11%
o: 10.5%
o: 21%
E: 100(1 + r)^2 = 121，1 + r = 1.1（−1.1 不合），r = 10%。
Q: 長 20 公尺、寬 15 公尺的長方形空地，開兩條寬度相同的直路，一條平行長邊、一條平行寬邊，各自貫穿整塊空地，剩下的面積是 234 平方公尺，路寬幾公尺？
o: 1
o*: 2
o: 3
o: 33
E: 把路移到邊上：(20 − x)(15 − x) = 234，x^2 − 35x + 66 = 0，(x − 2)(x − 33) = 0，33 比寬還大不合，路寬 2 公尺。
Q: 一個正方形的邊長增加 3 公分後，面積變成原來的 4 倍，原來的邊長是多少？
o: 1
o*: 3
o: 6
o: 9
E: (x + 3)^2 = 4x^2，x + 3 = 2x（邊長為正），x = 3。

# 累積次數
- 從第一組開始把次數依序累加，得到**累積次數**，表示「未滿某組上限」的資料個數。
- 最後一組的累積次數**等於資料總數**。
# 相對次數
- **相對次數** = 該組次數 ÷ 總次數，常用百分率表示；各組相對次數的和是 100%。
- **累積相對次數** = 累積次數 ÷ 總次數，最後一組是 100%。
- 例：40 人中 60~70 分有 12 人，相對次數 = \f{12}{40} = 30%。
# 累積次數分配折線圖
- 以各組的**上限**為橫坐標，累積次數（或累積相對次數）為縱坐標描點；從第一組下限、縱坐標 0 開始連線。
- 圖形由左往右只會**上升或持平**，不會下降。
- 從圖可以讀出**「某分數以下有多少人」**，或某個百分比大約落在哪一組。
! 讀表時分清楚問的是次數、相對次數，還是累積的值。
EX: 某班 40 人成績：50~60 有 6 人、60~70 有 12 人、70~80 有 10 人、80~90 有 8 人、90~100 有 4 人。未滿 80 分的有多少人？占全班幾 %？
=> 累積次數依序是 6、18、28、36、40
=> 未滿 80 分有 28 人，累積相對次數 \f{28}{40} = 70%
Q: 某班 40 人的成績分組中，80~90 分這一組有 8 人，前面各組累積到 28 人。這一組的相對次數是多少？
o*: 20%
o: 8%
o: 36%
o: 90%
E: 相對次數 = 8 ÷ 40 = 20%。累積到這一組是 36 人，那是累積次數，不是相對次數。
Q: 累積相對次數分配表中，最後一組的累積相對次數一定是多少？
o*: 100%
o: 50%
o: 0%
o: 等於最後一組的相對次數
E: 累加到最後一組時包含了全部資料，所以是 100%。
Q: 某次測驗 50 人，「未滿 60 分」的累積次數是 15，「未滿 70 分」的累積次數是 32。60 分以上、未滿 70 分的有幾人？
o: 15
o*: 17
o: 32
o: 47
E: 32 − 15 = 17。
Q: 某次測驗 50 人，「未滿 70 分」的累積次數是 32。70 分以上（含 70 分）有幾人？
o: 17
o*: 18
o: 32
o: 35
E: 全部 50 人減去未滿 70 分的 32 人，得 18 人。
