# 數列
- 依順序排成一列的數叫做**數列**，第 n 項記作 a_n，第一項 a_1 叫做首項。
- 項數有限的叫做有限數列，最後一項叫做**末項**。
- 找規律：看**相鄰兩項的差或比**，或觀察圖形怎麼一層層增加。
# 等差數列
- 相鄰兩項的差都相同的數列叫做**等差數列**，這個差叫做**公差** d：d = a_2 − a_1。
- 第 n 項：**a_n = a_1 + (n − 1)d**。
- 例：3、7、11、15、…，a_1 = 3，d = 4，a_{20} = 3 + 19 × 4 = 79。
# 等差中項與項數
- a、b、c 成等差數列時，b 叫做 a 與 c 的**等差中項**，b = \f{a + c}{2}。
- 從 a_1 到 a_n 共有 n 項：**n = \f{a_n − a_1}{d} + 1**。
- **a_m − a_n = (m − n)d**，例如 a_{10} − a_4 = 6d。
! 圖形題先數出前幾個圖形的數量，寫成數列後再找公差。
EX: 等差數列第 3 項是 11，第 8 項是 31，求首項與公差。
=> a_8 − a_3 = 5d = 20，d = 4
=> a_1 = a_3 − 2d = 11 − 8 = 3

# 級數
- 把數列各項用加號連起來叫做**級數**；等差數列各項的和叫做等差級數。
# 等差級數的和
- 前 n 項和：**S_n = \f{n(a_1 + a_n)}{2}**（首項加末項，乘以項數，再除以 2）。
- 也可以寫成 **S_n = \f{n[2a_1 + (n − 1)d]}{2}**。
- 例：1 + 2 + 3 + … + 100 = \f{100 × (1 + 100)}{2} = 5050。
! 先算出項數 n，再代入公式；項數是最容易算錯的地方。
# 常見應用
- 階梯座位、堆疊的罐頭：每排比前一排多（或少）**固定個數**，求總數。
- 前 n 個正奇數的和：1 + 3 + 5 + … + **(2n − 1) = n^2**。
EX: 求 7 + 11 + 15 + … + 87 的和。
=> 公差 4，項數 n = \f{87 − 7}{4} + 1 = 21
=> S = \f{21 × (7 + 87)}{2} = \f{21 × 94}{2} = 987

# 等比數列
- 每一項除以前一項的比值都相同的數列叫做**等比數列**，這個比值叫做**公比** r（各項與 r 都不為 0）。
- 第 n 項：**a_n = a_1 × r^{n−1}**。
- 例：3、6、12、24、…，a_1 = 3，r = 2，a_8 = 3 × 2^7 = 384。
- 公比是負數時，各項**正負交錯**，例如 1、−2、4、−8、…。
# 等比中項
- a、b、c 成等比數列時，b 叫做 a 與 c 的**等比中項**，b^2 = ac。
- 例：4 與 9 的等比中項是 6 或 −6。
# 生活中的等比
- 每年成長固定的百分率 p%：n 年後的量 = **原量 × (1 + p%)^n**。
- 每次減少一半：**原量 × (\f{1}{2})^n**。
! 「每年增加 2.5%」是每年乘以 1.025，不是每年加上固定的數。
EX: 某城市人口 50 萬，每年增加 2%，3 年後約有多少萬人？
=> 50 × 1.02^3 = 50 × 1.061208
=> 約 53.06 萬人

o*: 162
E: 公比 r = −3，a_5 = 2 × (−3)^4 = 2 × 81 = 162。

o*: 9 或 −9
o: 9

E: x^2 = 3 × 27 = 81，x = ±9。

o: 12
o: 32

E: 每對摺一次層數乘以 2，6 次後是 2^6 = 64 層。

# 函數
- 變數 x 的值確定時，另一個變數 y 的值也**唯一**確定，就說 y 是 x 的**函數**，記作 y = f(x)。
- f(a) 表示 x = a 時的**函數值**，例如 f(x) = 2x − 1，f(3) = 5。
# 線型函數
- 形如 y = ax + b（a、b 為常數）的函數叫做**線型函數**，圖形是一條直線。
- a ≠ 0 時是**一次函數**；a = 0 時 y = b 是**常數函數**，圖形是水平線。
- b 是圖形與 **y 軸交點的 y 坐標**。
# 圖形的方向
- a > 0：x 增加時 y 也增加，圖形**由左下往右上**。
- a < 0：x 增加時 y 減少，圖形**由左上往右下**。
- |a| 越大直線越陡；a 相同的兩條直線**互相平行**。
# 求函數與應用
- 已知兩組 (x, y)：設 y = ax + b，代入後**解聯立方程式**。
- 生活中常見**「起始值 + 每單位的變化量 × 數量」**，例如計程車資、手機費、水溫變化。
! 鉛垂線 x = h 不是函數的圖形，因為同一個 x 對應了無限多個 y。
EX: 一次函數的圖形通過 (2, 1) 與 (−1, 7)，求這個函數。
=> 設 y = ax + b：\sys{2a + b = 1}{−a + b = 7}
=> 相減得 3a = −6，a = −2，b = 5，函數為 y = −2x + 5
Q: f(x) = −3x + 4，則 f(−2) 是多少？
o: −10
o: −2
o: 2
o*: 10
E: f(−2) = −3 × (−2) + 4 = 6 + 4 = 10。
Q: 一次函數 y = 2x − 6 的圖形與 x 軸的交點是哪一點？
o*: (3, 0)
o: (0, −6)
o: (−3, 0)
o: (0, 3)
E: x 軸上 y = 0：2x − 6 = 0，x = 3。(0, −6) 是與 y 軸的交點。
Q: 下列哪一個函數的圖形由左上往右下？
o*: y = −x + 3
o: y = 2x − 1
o: y = 5
o: y = \f{1}{2}x
E: x 的係數為負，x 增加時 y 減少，圖形往右下。

o: y = 85x + 25
o: y = 110x

E: 起始值 85，每公里增加 25，所以 y = 25x + 85。

# 三角形的內角與外角
- 三角形三個內角的和是 **180°**。
- 一邊延長所形成的角叫做**外角**，外角與相鄰的內角互補。
- **外角等於兩個內對角的和**：∠ACD = ∠A + ∠B。
- 一個三角形**最多只有一個直角或鈍角**。
# 多邊形的內角和
- 從 n 邊形的一個頂點畫對角線，可以把它分成 **(n − 2) 個三角形**。
- n 邊形內角和 = **(n − 2) × 180°**，例如六邊形內角和 720°。
- 正 n 邊形每個內角 = **\f{(n − 2) × 180°}{n}**。
# 外角和
- 任何凸多邊形的外角和都是 **360°**（每個頂點取一個外角）。
- 正 n 邊形每個外角 = **\f{360°}{n}**，也可以反過來求邊數：每個外角 40°，n = 9。
! 已知正多邊形每個內角時，先算外角 = 180° − 內角，再用 360° 除以外角求邊數。
EX: 正多邊形的每個內角是 144°，它是正幾邊形？
=> 每個外角 = 180° − 144° = 36°
=> 邊數 = 360° ÷ 36° = 10，是正十邊形。

o: 61
o: 113
o*: 119
o: 128
E: 外角等於兩內對角的和：52° + 67° = 119°。
Q: 八邊形的內角和是幾度？
o: 360
o: 900
o*: 1080
o: 1440
E: (8 − 2) × 180° = 1080°。
Q: 正十二邊形的每個內角是幾度？
o: 30
o: 144
o*: 150
o: 160
E: 每個外角 360° ÷ 12 = 30°，內角 = 180° − 30° = 150°。
Q: 一個凸多邊形的內角和是外角和的 4 倍，它是幾邊形？
o: 8
o: 9
o*: 10
o: 12
E: (n − 2) × 180° = 4 × 360° = 1440°，n − 2 = 8，n = 10。

# 尺規作圖的規則
- 只用**沒有刻度的直尺**和圓規作圖：直尺用來連線、延長，圓規用來畫弧、截取等長。
- 要**保留作圖痕跡**（弧線），並說得出為什麼這樣作是對的。
# 基本作圖
- 作一線段等於已知線段：**用圓規量取長度**，在直線上截取。
- 作一角等於已知角：以頂點為圓心畫弧，量取弧上兩交點的距離，**到新位置複製**。
- 作線段的**中垂線**：分別以兩端點為圓心、大於線段一半的長為半徑畫弧，連接兩弧的交點。
- 作角的**角平分線**：以頂點為圓心畫弧交兩邊，再以兩交點為圓心、相同半徑畫弧相交，連接頂點與交點。
- 過一點作已知直線的**垂線**：點在線上或線外都可以，先畫弧找出兩個與該點等距的點。
! 中垂線和角平分線的作法正確，原因都是作出的兩個三角形 SSS 全等。
# 延伸作圖
- 作垂線得 90°，**平分得 45°**；作正三角形得 60°，平分得 30°。
- 三角形三邊的中垂線交於**外心**，三個角的角平分線交於**內心**（九上會學）。
EX: 只用尺規，怎樣作出 75° 的角？
=> 作正三角形得 60°，再作垂線得 90°，兩者相差 30°，平分得 15°。
=> 60° + 15° = 75°（也可以用 45° + 30°）。

o: 等於 \seg{AB} 的一半
o: 小於 \seg{AB} 的一半
o: 兩次可以不同
E: 半徑大於一半時兩弧才會相交於兩點；兩次半徑相同，交點才會在中垂線上。
Q: 尺規作圖中，直尺可以用來做什麼？
o*: 連接兩點或延長線段
o: 量取線段長度
o: 量角度
o: 畫圓弧
E: 尺規作圖的直尺沒有刻度，只能畫直線；量取等長要用圓規。

o*: 20°

# 全等圖形
- 兩個圖形能完全疊合叫做**全等**，記作 △ABC ≅ △DEF，對應頂點要依序寫。
- 全等三角形的**對應邊相等、對應角相等**。
# 判別全等
- **SSS**：三邊對應相等。
- **SAS**：兩邊及其夾角對應相等。
- **ASA**：兩角及其夾邊對應相等。
- **AAS**：兩角及其中一角的對邊對應相等。
- **RHS**：兩個直角三角形的斜邊與一股對應相等。
! SSA（兩邊與其中一邊的對角）和 AAA 都**不能**保證全等。
# 用全等證明
- 要說明兩線段等長或兩角相等，常找出包含它們的兩個三角形，**先證明全等**。
- **寫出每個條件的理由**，例如「已知」、「公共邊」、「對頂角相等」。
EX: 四邊形 ABCD 中，\seg{AB} = \seg{AD}，\seg{CB} = \seg{CD}，說明 ∠B = ∠D。
=> 連 \seg{AC}：\seg{AB} = \seg{AD}，\seg{CB} = \seg{CD}，\seg{AC} 是公共邊。
=> △ABC ≅ △ADC（SSS），所以對應角 ∠B = ∠D。

o*: AAA
o: SAS
o: ASA
o: SSS
E: 三個角相等只能保證形狀相同（相似），大小可能不同。

o*: 60
o: 70
o: 80
E: 對應關係 A↔P、B↔Q、C↔R，∠P = 50°，∠R = 180° − 50° − 70° = 60°。
Q: 兩個直角三角形的斜邊相等、一股也相等，可以直接用哪一個性質判定全等？
o*: RHS
o: SAS
o: ASA
o: AAS
E: 直角、斜邊、一股對應相等，就是 RHS。

# 中垂線的性質
- **中垂線上任一點到線段兩端點的距離相等**。
- 反過來，到線段兩端點等距的點，**一定在這條線段的中垂線上**。
- 例：P 在 \seg{AB} 的中垂線上，則 \seg{PA} = \seg{PB}，△PAB 是等腰三角形。
# 角平分線的性質
- **角平分線上任一點到角的兩邊距離相等**（距離是垂直距離）。
- 反過來，在角的內部到兩邊等距的點，**一定在這個角的角平分線上**。
# 等腰三角形
- 兩腰等長的三角形，兩個**底角相等**；反過來，兩角相等的三角形是等腰三角形。
- 頂角平分線、底邊上的中線、底邊上的高、底邊的中垂線，**四線重合**。
- 正三角形三邊相等，**每個內角 60°**。
# 直角三角形斜邊上的中點
- 直角三角形斜邊的中點到三個頂點的距離相等，所以**斜邊上的中線等於斜邊的一半**。
EX: △ABC 中，\seg{AB} = \seg{AC}，∠A = 40°，求 ∠B。
=> 兩腰相等，兩底角相等：∠B = ∠C
=> ∠B = (180° − 40°) ÷ 2 = 70°

# 三邊的關係
- 三角形**任意兩邊的和大於第三邊**，任意兩邊的差小於第三邊。
- 判斷三個數能否當三角形的邊長：檢查**「兩短邊的和 > 最長邊」**即可。
- 兩邊長 a、b（a > b）時，第三邊 x 的範圍是 **a − b < x < a + b**。
# 邊與角的關係
- 同一個三角形中，**大邊對大角，大角對大邊**。
- 例：\seg{BC} > \seg{AC} > \seg{AB}，則 ∠A > ∠B > ∠C。
- 直角或鈍角所對的邊是**最長的邊**。
# 兩個三角形的比較
- 兩個三角形有兩邊對應相等時，**夾角較大的那個，第三邊也較長**；反過來也成立。
! 外角大於任何一個內對角，也可以用來比較角的大小。
EX: 三角形兩邊長 4 和 9，第三邊是整數，有幾種可能？
=> 9 − 4 < x < 9 + 4，即 5 < x < 13
=> x = 6、7、…、12，共 7 種
Q: 下列哪一組數可以作為三角形的三邊長？
o*: 5、7、11
o: 3、4、8
o: 2、6、8
o: 1、2、3
E: 5 + 7 = 12 > 11；其他組的兩短邊和都不大於最長邊。
Q: △ABC 中，\seg{AB} = 6，\seg{BC} = 9，\seg{CA} = 7，哪一個角最大？
o*: ∠A
o: ∠B
o: ∠C
o: 無法判斷
E: 最長邊 \seg{BC} 所對的角是 ∠A。
Q: 三角形兩邊長 5 和 12，第三邊 x 的範圍是什麼？
o*: 7 < x < 17
o: 5 < x < 12
o: 7 ≤ x ≤ 17
o: x < 17
E: 12 − 5 < x < 12 + 5。等於 7 或 17 時三點共線，不能成為三角形。
Q: △ABC 中，∠A = 50°，∠B = 75°，最短的邊是哪一邊？
o*: \seg{BC}
o: \seg{AC}
o: \seg{AB}
o: 無法判斷
E: ∠C = 55°，最小角是 ∠A，它所對的 \seg{BC} 最短。

# 平行
- 同一平面上兩條直線不相交，叫做**平行**，記作 L_1 ∥ L_2。
- 兩平行線之間的**距離處處相等**；過直線外一點，只能作一條直線與它平行。
# 截線與截角
- 一條直線與兩條直線相交，這條直線叫做截線，形成**同位角**、**內錯角**、**同側內角**。
- 兩直線平行時：同位角相等、內錯角相等、同側內角**互補**（和為 180°）。
- 反過來，只要同位角相等、內錯角相等或同側內角互補，**兩直線就平行**。
# 常用技巧
- 角度題中出現「拐角」時，過拐點**作一條平行線**，把它拆成兩個內錯角。
- 例：L_1 ∥ L_2，兩線之間的拐角 = 兩側與平行線所夾的角相加。
! 判斷平行要用角的關係，不能只看圖形像不像。
EX: L_1 ∥ L_2，被截線所截的一組同側內角分別是 3x° 與 (x + 40)°，求 x 與兩角。
=> 同側內角互補：3x + x + 40 = 180
=> x = 35，兩角為 105° 與 75°
Q: L_1 ∥ L_2，其中一個內錯角是 72°，與它成內錯角的另一個角是幾度？
o: 18
o*: 72
o: 108
o: 144
E: 兩直線平行時，內錯角相等。
Q: 兩直線被一條截線所截，下列哪一個條件可以判定兩直線平行？
o*: 同位角相等
o: 同側內角相等
o: 對頂角相等
o: 內錯角互補
E: 同位角相等可推得平行；同側內角要「互補」才行，對頂角本來就相等。
Q: L_1 ∥ L_2，一組同側內角是 (2x + 10)° 與 (3x − 30)°，x 是多少？
o: 36
o: 38
o*: 40
o: 44
E: (2x + 10) + (3x − 30) = 180，5x = 200，x = 40。
Q: 過直線 L 外一點 P，可以作幾條直線與 L 平行？
o*: 恰好 1 條
o: 2 條
o: 無限多條
o: 0 條
E: 過直線外一點，恰有一條直線與它平行。

# 平行四邊形的性質
- 兩組對邊分別平行的四邊形叫做**平行四邊形**。
- 性質：**兩組對邊等長**、**兩組對角相等**、**對角線互相平分**、相鄰兩角互補。
- 一條對角線把它分成**兩個全等三角形**；兩條對角線把它分成四個面積相等的三角形。
# 判別平行四邊形
- 兩組對邊分別平行，或**兩組對邊分別等長**。
- 一組對邊**平行且等長**。
- 兩組對角分別相等，或**兩條對角線互相平分**。
! 「一組對邊平行、另一組對邊等長」不一定是平行四邊形，可能是等腰梯形。
# 面積
- 平行四邊形面積 = **底 × 高**。
- **同底等高的平行四邊形面積相等**；三角形面積是同底等高平行四邊形的一半。
EX: 平行四邊形 ABCD 中，∠A = 3∠B，求 ∠C。
=> 相鄰兩角互補：∠A + ∠B = 180°，4∠B = 180°，∠B = 45°
=> ∠A = 135°，對角相等，∠C = ∠A = 135°
Q: 平行四邊形 ABCD 中，∠B = 68°，∠D 是幾度？
o: 22
o*: 68
o: 112
o: 136
E: ∠B 與 ∠D 是對角，對角相等。
Q: 平行四邊形的兩條對角線長 10 和 16，交點 O 到四個頂點的距離分別是多少？
o*: 5、5、8、8
o: 10、10、16、16
o: 6.5、6.5、6.5、6.5
o: 4、4、6、6
E: 對角線互相平分，各被分成兩半：10 ÷ 2 = 5，16 ÷ 2 = 8。
Q: 下列哪一個條件可以判定四邊形 ABCD 是平行四邊形？

o: ∠A = ∠B
o: \seg{AC} = \seg{BD}
E: 一組對邊平行且等長就是平行四邊形；第二個選項可能是等腰梯形。

# 長方形、菱形、正方形
- **長方形**：四個角都是直角；對角線**等長**且互相平分。
- **菱形**：四邊等長；對角線**互相垂直平分**，並平分各內角；面積 = 兩對角線乘積 ÷ 2。
- **正方形**：同時是長方形和菱形，對角線等長且互相垂直平分，與邊夾 45°。
# 箏形與梯形
- **箏形**：兩組鄰邊分別等長；對角線互相垂直，其中一條被另一條垂直平分；面積 = 兩對角線乘積 ÷ 2。
- **梯形**：只有一組對邊平行，平行的兩邊叫上底和下底；面積 = (上底 + 下底) × 高 ÷ 2。
- **等腰梯形**：兩腰等長，同一底上的兩底角相等，兩條對角線等長。
# 中點連線
- 三角形兩邊中點的連線**平行第三邊，長度是第三邊的一半**。
- 梯形兩腰中點的連線叫做**中線**，平行兩底，長 = (上底 + 下底) ÷ 2。
! 對角線互相垂直的四邊形（菱形、正方形、箏形），面積都等於兩對角線乘積的一半。
EX: 菱形兩條對角線長 6 和 8，求邊長與面積。
=> 對角線互相垂直平分，一半是 3 和 4，邊長 = \r{3^2 + 4^2} = 5
=> 面積 = 6 × 8 ÷ 2 = 24
