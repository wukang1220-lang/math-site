@ 5-1-1
sum: 把兩個比合成連比，並按連比分配。
# 連比
- 三個或更多個數 a、b、c 的比寫成 a : b : c，叫做**連比**。
- 各項同乘或同除一個不為 0 的數，**連比不變**；各項化成互質的整數，叫做最簡整數連比。
- 由兩個比求連比：**把共同的那一項化成相同的數**。例：a : b = 2 : 3，b : c = 4 : 5，b 取 [3, 4] = 12，得 a : b : c = 8 : 12 : 15。
# 連比例式
- a : b : c = d : e : f 表示 a : b = d : e、b : c = e : f、a : c = d : f **同時成立**。
- 若 x : y : z = a : b : c，可以設 **x = ar、y = br、z = cr**（r ≠ 0）。
# 按連比分配
- 把 N 按 a : b : c 分配，各得 **N × \f{a}{a + b + c}**、N × \f{b}{a + b + c}、N × \f{c}{a + b + c}。
- 例：三角形三內角的比是 2 : 3 : 4，三內角分別是 40°、60°、80°。
! 「x 比 y 多 20%」可以寫成 x : y = 1.2 : 1 = 6 : 5。
EX: a : b = 3 : 4，b : c = 6 : 7，求 a : b : c。
=> b 的兩個值 4 與 6 的最小公倍數是 12
=> a : b = 9 : 12，b : c = 12 : 14，所以 a : b : c = 9 : 12 : 14
Q: 若 x : y = 2 : 5，y : z = 3 : 4，則 x : y : z 是多少？
o*: 6 : 15 : 20
o: 2 : 15 : 4
o: 6 : 5 : 4
o: 2 : 8 : 4
E: y 取 [5, 3] = 15：x : y = 6 : 15，y : z = 15 : 20。

o: 30
o: 60
o*: 90
o: 120
E: 180° × \f{3}{1 + 2 + 3} = 90°。
Q: 把 360 元按 2 : 3 : 7 分給甲、乙、丙，丙得多少元？
o: 120
o: 180

# 三角形面積比
- 高相等的三角形，**面積比等於底邊的比**。
- 例：D 在 \seg{BC} 上，△ABD 面積 : △ADC 面積 = \seg{BD} : \seg{DC}。
# 平行線截比例線段
- △ABC 中，D、E 分別在 \seg{AB}、\seg{AC} 上，若 \seg{DE} ∥ \seg{BC}，則 **\seg{AD} : \seg{DB} = \seg{AE} : \seg{EC}**。
- 也有 \seg{AD} : \seg{AB} = \seg{AE} : \seg{AC} = **\seg{DE} : \seg{BC}**。
- 反過來，若 \seg{AD} : \seg{DB} = \seg{AE} : \seg{EC}，**則 \seg{DE} ∥ \seg{BC}**。
! 求 \seg{DE} 時要用「小三角形的邊 : 大三角形的邊」，不能用 \seg{AD} : \seg{DB}。
# 多條平行線
- 三條以上的平行線截兩條直線，截得的**對應線段成比例**。
- 例：L_1 ∥ L_2 ∥ L_3 截直線 M 得 2 和 3，截直線 N 得 4 和 x，則 2 : 3 = 4 : x，x = 6。
# 中點連線
- D、E 是 \seg{AB}、\seg{AC} 的中點時，\seg{DE} ∥ \seg{BC}，**\seg{DE} = \f{1}{2}\seg{BC}**，是比例線段的特例。
EX: △ABC 中 \seg{DE} ∥ \seg{BC}，\seg{AD} = 6，\seg{DB} = 4，\seg{BC} = 15，求 \seg{DE}。
=> \seg{AD} : \seg{AB} = \seg{DE} : \seg{BC}，6 : 10 = \seg{DE} : 15

# 相似形
- 形狀相同、大小不一定相同的圖形叫做**相似形**；把圖形放大或縮小得到的圖形與原圖相似。
- 兩個多邊形相似：**對應角相等**，而且**對應邊成比例**，記作 ∼。
- 對應邊的比叫做**相似比**（縮放比）。
# 三角形相似的判別
- **AA**：兩組對應角相等。
- **SAS**：兩組對應邊成比例，而且夾角相等。
- **SSS**：三組對應邊成比例。
! 寫 △ABC ∼ △DEF 時，頂點要依對應順序寫，才看得出哪兩邊對應。
# 相似形的性質
- **周長比 = 對應邊長比**；對應的高、中線、角平分線的比也等於邊長比。
- **面積比 = 邊長比的平方**：邊長比 2 : 3，面積比 4 : 9。
- 所有的**正方形、正三角形、圓都相似**。
EX: △ABC ∼ △DEF，\seg{AB} = 6，\seg{DE} = 9，△ABC 的面積是 20，求 △DEF 的面積。
=> 相似比 6 : 9 = 2 : 3，面積比 4 : 9
=> △DEF 面積 = 20 × \f{9}{4} = 45
Q: 下列哪一組圖形一定相似？
o*: 兩個正方形
o: 兩個長方形
o: 兩個菱形
o: 兩個等腰三角形
E: 正方形的角都是 90°、邊都等長，一定相似；長方形的長寬比可以不同。
Q: △ABC ∼ △PQR，\seg{AB} : \seg{PQ} = 3 : 5，△ABC 的周長是 24，△PQR 的周長是多少？
o: 14.4
o: 30
o*: 40
o: 48
E: 周長比 = 邊長比 3 : 5，24 × \f{5}{3} = 40。
Q: 兩個相似三角形的面積比是 16 : 25，對應邊的比是多少？
o*: 4 : 5
o: 16 : 25
o: 256 : 625
o: 2 : 5
E: 面積比是邊長比的平方，所以邊長比是 \r{16} : \r{25} = 4 : 5。

o*: 相似（AA）

o: 不一定相似
o: 相似（SSS）

# 相似的應用
- 測量高度：同一時間，**物高與影長成正比**（陽光視為平行光）。
- 例：1.6 公尺的人影長 2 公尺，同時旗桿影長 15 公尺，旗桿高 1.6 × \f{15}{2} = 12 公尺。
- 直角三角形斜邊上的高，把原三角形分成兩個**與原三角形相似**的直角三角形。
# 三角比
- 直角三角形中，**銳角的大小決定三邊的比值**，和三角形的大小無關。
- ∠A 為銳角：**sin A** = \f{對邊}{斜邊}，**cos A** = \f{鄰邊}{斜邊}，**tan A** = \f{對邊}{鄰邊}。
- 例：兩股 3、4，斜邊 5，最小角 A 的 sin A = \f{3}{5}，cos A = \f{4}{5}，tan A = \f{3}{4}。
# 特殊直角三角形
- 30°－60°－90°：三邊比 **1 : \r{3} : 2**（30° 對最短邊，直角對斜邊）。
- 45°－45°－90°：三邊比 **1 : 1 : \r{2}**。
- **sin 30° = \f{1}{2}**，cos 30° = \f{\r{3}}{2}，tan 45° = 1，tan 60° = \r{3}。
! 先確定是哪一個角，再分清楚對邊與鄰邊；斜邊永遠是直角的對邊。
EX: 斜坡與地面夾 30°，沿斜坡走了 50 公尺，上升的高度是多少？
=> 高度是 30° 的對邊，斜坡是斜邊
=> 高度 = 50 × sin 30° = 50 × \f{1}{2} = 25 公尺
Q: 直角三角形 ABC 中 ∠C = 90°，\seg{BC} = 5，\seg{AC} = 12，∠A 的對邊與鄰邊的比值（tan A）是多少？
o*: \f{5}{12}
o: \f{12}{5}
o: \f{5}{13}
o: \f{12}{13}
E: ∠A 的對邊是 \seg{BC} = 5，鄰邊是 \seg{AC} = 12，tan A = \f{5}{12}。
Q: 30°－60°－90° 的直角三角形，最短邊長 4，斜邊長是多少？
o*: 8
o: 4\r{3}
o: 4\r{2}
o: 6
E: 邊長比 1 : \r{3} : 2，最短邊 4，斜邊 4 × 2 = 8。
Q: 等腰直角三角形的斜邊長 10，一股長是多少？
o: 5
o*: 5\r{2}
o: 5\r{3}
o: 10\r{2}
E: 邊長比 1 : 1 : \r{2}，股 = \f{10}{\r{2}} = 5\r{2}。
Q: 在水平地面上，身高 150 公分的人直立時影長 90 公分，同一時間一棵直立的樹影長 6 公尺，樹高幾公尺？
o: 3.6
o: 9
o*: 10
o: 12
E: 物高與影長成正比：150 : 90 = 樹高 : 6，樹高 = 10 公尺。

# 圓的名詞
- 圓上任兩點的連線叫做**弦**，通過圓心的弦叫做直徑；圓上兩點之間的部分叫做**弧**。
- 大於半圓的弧叫**優弧**，小於半圓的弧叫**劣弧**；弦與弧圍成的區域叫弓形。
- 兩條半徑與弧圍成的區域叫做**扇形**，兩半徑的夾角是圓心角。
# 弧長與扇形面積
- 半徑 r、圓心角 θ°：**弧長 = 2πr × \f{θ}{360}**，扇形面積 = πr^2 × \f{θ}{360}。
- 例：半徑 6、圓心角 60°，弧長 = 2π × 6 × \f{1}{6} = 2π，扇形面積 = 36π × \f{1}{6} = 6π。
# 點、直線與圓
- 點到圓心的距離 d 與半徑 r 比較：**d < r 在圓內**，d = r 在圓上，d > r 在圓外。
- 圓心到直線的距離 d：d > r 不相交，d = r **相切**（只有一個交點），d < r 交於兩點。
# 弦心距與切線
- 圓心到弦的垂直線段叫做**弦心距**，它**垂直平分這條弦**：半弦、弦心距、半徑構成直角三角形。
- 切線與過切點的半徑**互相垂直**。
- 從圓外一點對圓作兩條切線，兩條**切線段等長**。
! 看到切線就連半徑造直角，看到弦就作弦心距，再用畢氏定理。
EX: 圓的半徑 13，某弦的弦心距是 5，弦長是多少？
=> 半弦長 = \r{13^2 − 5^2} = \r{144} = 12
=> 弦長 = 24
Q: 圓 O 的半徑是 5，直線 L 與圓心的距離是 5，L 與圓的關係是什麼？
o*: 相切
o: 交於兩點
o: 不相交
o: 無法判斷
E: 圓心到直線的距離等於半徑，直線與圓相切。
Q: 半徑 10 的圓中有一條長 16 的弦，弦心距是多少？
o: 4
o*: 6
o: 8
o: 12
E: 半弦 8，弦心距 = \r{10^2 − 8^2} = \r{36} = 6。
Q: 半徑 9、圓心角 120° 的扇形面積是多少？
o*: 27π
o: 6π
o: 54π
o: 81π
E: 81π × \f{120}{360} = 27π。
Q: P 在圓 O 外，\seg{PA}、\seg{PB} 分別切圓於 A、B，\seg{PA} = 7，半徑 3，\seg{PB} 是多少？
o: 3
o: 4
o*: 7
o: 10
E: 圓外一點的兩條切線段等長，\seg{PB} = \seg{PA} = 7。

# 圓心角
- 頂點在圓心的角叫做**圓心角**，它的度數等於所對弧的度數。
- 同圓或等圓中，相等的圓心角所對的**弧相等、弦也相等**。
# 圓周角
- 頂點在圓上、兩邊都與圓相交的角叫做**圓周角**。
- **圓周角 = 所對弧度數的一半**，也就是同弧所對圓心角的一半。
- 同弧或等弧所對的**圓周角都相等**。
- **直徑（半圓）所對的圓周角是 90°**；反過來，90° 的圓周角所對的弦是直徑。
# 圓內接四邊形
- 四個頂點都在圓上的四邊形叫做圓內接四邊形，它的**對角互補**。
- 例：圓內接四邊形 ABCD 中 ∠A = 75°，則 ∠C = 105°。
! 找圓周角「所對的弧」，要看角的兩邊夾住的那一段弧，不是頂點所在的那一段。
EX: 圓 O 上有 A、B、C 三點，∠AOB = 110°，C 在優弧上，求 ∠ACB。
=> ∠ACB 所對的是劣弧 AB，劣弧 AB = 110°
=> ∠ACB = 110° ÷ 2 = 55°

o*: 5
o: 7
o: 10
o: 14
E: 直徑所對的圓周角 ∠ACB = 90°，\seg{AB} = \r{6^2 + 8^2} = 10，半徑 5。

sum: 從已知條件與性質出發，寫出每一步都有理由的證明。
# 證明的意義
- **證明**是從已知條件出發，依據已確定的定義與性質，一步一步推出結論。
- 每一步都要**寫出依據**，例如「已知」、「對頂角相等」、「SAS 全等」、「三角形內角和 180°」。
- 看起來像、量起來相等，都**不能當作證明的理由**。
# 常用的依據
- **對頂角相等**；兩直線平行時同位角、內錯角相等；三角形內角和 180°；外角等於兩內對角的和。
- 全等三角形的**對應邊、對應角相等**；等腰三角形兩底角相等。
- 相似三角形**對應邊成比例**；圓周角等於所對弧的一半。
# 證明的寫法
- 先寫出**「已知」與「求證」**，畫圖並標出條件。
- **從結論往回想**：要證兩線段相等，找包含它們的兩個全等三角形；要證兩角相等，找平行線或等腰三角形。
- 用**「因為……所以……」**把步驟串起來，最後寫出結論。
! 注意方向：「兩直線平行 → 同位角相等」與「同位角相等 → 兩直線平行」是兩個不同的性質，要選對。
# 反例
- 要說明一個敘述是錯的，只要找到一個不符合的例子（**反例**）就夠了。
EX: \seg{AB} 與 \seg{CD} 交於 O，O 是兩線段的中點。說明 \seg{AC} ∥ \seg{BD}。
=> \seg{OA} = \seg{OB}，\seg{OC} = \seg{OD}，∠AOC = ∠BOD（對頂角相等），所以 △AOC ≅ △BOD（SAS）
=> 對應角 ∠OAC = ∠OBD，這是一組內錯角，所以 \seg{AC} ∥ \seg{BD}
Q: 下列哪一個可以當作證明中的理由？
o*: 對頂角相等
o: 從圖上看起來相等
o: 用量角器量出來相等
o: 多畫幾個例子都成立
E: 證明要用已確定的性質；看起來、量出來或舉幾個例子都不夠。
Q: 要說明「所有質數都是奇數」是錯的，最簡單的方法是什麼？
o*: 舉出反例：2 是偶數也是質數
o: 列出 10 個奇數質數
o: 說明奇數有無限多個
o: 畫出數線
E: 只要找到一個反例，就能說明敘述錯誤。
Q: △ABC 中 \seg{AB} = \seg{AC}，D 是 \seg{BC} 的中點。要證明 △ABD ≅ △ACD，最直接的依據是什麼？
o*: SSS
o: AAA
o: SSA
o: RHS
E: \seg{AB} = \seg{AC}，\seg{BD} = \seg{CD}，\seg{AD} 是公共邊，三邊對應相等。題目沒有直接給直角，不能先用 RHS。
Q: 已知 L_1 ∥ L_2，要推出一組同位角相等，應該寫哪一個理由？
o*: 兩直線平行，同位角相等
o: 同位角相等，兩直線平行
o: 對頂角相等
o: 三角形內角和是 180°
E: 由「平行」推到「角相等」，用的是平行線的性質；反方向才是平行的判別。

# 外心
- 三角形三邊的**中垂線**交於一點，叫做**外心** O；外心到三頂點等距，是外接圓的圓心。
- 銳角三角形的外心在內部，直角三角形的外心在**斜邊中點**，鈍角三角形的外心在外部。
- 直角三角形的外接圓半徑 = **斜邊的一半**。
# 內心
- 三角形三個角的**角平分線**交於一點，叫做**內心** I；內心到三邊等距，是內切圓的圓心。
- 內心一定在三角形內部；**∠BIC = 90° + \f{1}{2}∠A**。
- 三角形面積 = **\f{1}{2} × 內切圓半徑 × 周長**；直角三角形內切圓半徑 r = \f{a + b − c}{2}（c 為斜邊）。
# 重心
- 三條**中線**交於一點，叫做**重心** G；重心一定在三角形內部。
- 重心把每條中線分成 **2 : 1**（頂點到重心 : 重心到對邊中點）。
- 重心與三頂點的連線把三角形分成**三個面積相等的三角形**；三條中線把三角形分成六塊等面積。
# 正三角形
- 正三角形的外心、內心、重心是**同一點**；外接圓半徑是內切圓半徑的 2 倍。
! 外心找中垂線（到頂點等距），內心找角平分線（到邊等距），重心找中線（分成 2 : 1）。
EX: 直角三角形兩股 6、8，求外接圓與內切圓的半徑。
=> 斜邊 = 10，外心在斜邊中點，外接圓半徑 = 5
=> 內切圓半徑 r = \f{6 + 8 − 10}{2} = 2
Q: △ABC 中 ∠A = 70°，I 是內心，∠BIC 是幾度？
o: 110
o*: 125
o: 140
o: 145
E: ∠BIC = 90° + \f{1}{2} × 70° = 125°。
Q: G 是 △ABC 的重心，中線 \seg{AD} = 12，\seg{AG} 是多少？
o: 4
o: 6
o*: 8
o: 9
E: \seg{AG} : \seg{GD} = 2 : 1，\seg{AG} = 12 × \f{2}{3} = 8。
Q: 哪一種三角形的外心在三角形外部？
o*: 鈍角三角形
o: 銳角三角形
o: 直角三角形
o: 正三角形
E: 銳角在內部、直角在斜邊中點、鈍角在外部。
Q: △ABC 的面積是 36，G 是重心，△GBC 的面積是多少？
o: 6
o: 9
o*: 12
o: 18
E: 重心與三頂點連線分成三個等面積的三角形，36 ÷ 3 = 12。
