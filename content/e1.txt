// 第一冊新增例題（每單元補 2 題，與原有 1 題合計 3 題；皆為自編）

@+ 1-1-1
EX: 把 −2.5、3、−4、0、\f{1}{2} 由小到大排列。
=> 負數小於 0，0 小於正數；兩個負數中 |−4| > |−2.5|，所以 −4 < −2.5。
=> −4 < −2.5 < 0 < \f{1}{2} < 3
EX: 若 |x| = 3 且 x < 0，求 x；若 |y − 1| = 0，求 y。
=> 絕對值是 3 的數有 3 和 −3，又 x < 0，所以 x = −3。
=> 只有 0 的絕對值是 0，所以 y − 1 = 0，y = 1。

@+ 1-1-2
EX: 計算 −7 − (−12) + (−9) − 4。
=> 把減法改成加法：−7 + 12 + (−9) + (−4)
=> = 5 + (−9) + (−4) = −4 + (−4) = −8
EX: 數線上 A(−9)、B(5)，求 \seg{AB} 的長與中點 M 的坐標。
=> \seg{AB} = |−9 − 5| = 14
=> M 的坐標 = \f{−9 + 5}{2} = −2

@+ 1-1-3
EX: 計算 (−48) ÷ 6 × (−3)。
=> 乘除同級，由左往右：(−48) ÷ 6 = −8
=> (−8) × (−3) = 24
EX: 利用分配律計算 (−25) × 39 + (−25) × 61。
=> = (−25) × (39 + 61)
=> = (−25) × 100 = −2500

@+ 1-1-4
EX: 計算 (−2)^3 − 3^2 × (−1)^4。
=> (−2)^3 = −8，3^2 = 9，(−1)^4 = 1
=> −8 − 9 × 1 = −17
EX: 比較 a = 4.5 × 10^{−6} 與 b = 9 × 10^{−7} 的大小，並把 a 寫成小數。
=> 先比指數：−6 > −7，所以 a > b。
=> a = 0.0000045，從小數點後第 6 位開始出現不是 0 的數字。

@+ 1-2-1
EX: 判斷 7425 是不是 3、5、9、11 的倍數。
=> 數字和 7 + 4 + 2 + 5 = 18，是 3 和 9 的倍數；個位數是 5，是 5 的倍數。
=> 奇數位數字和 5 + 4 = 9，偶數位數字和 2 + 7 = 9，差是 0，所以也是 11 的倍數（7425 = 11 × 675）。
EX: 求 540 的標準分解式與正因數個數。
=> 540 = 4 × 135 = 2^2 × 3^3 × 5
=> 正因數個數 = (2 + 1)(3 + 1)(1 + 1) = 24 個

@+ 1-2-2
EX: 求 (90, 126) 與 [90, 126]。
=> 90 = 2 × 3^2 × 5，126 = 2 × 3^2 × 7
=> (90, 126) = 2 × 3^2 = 18；[90, 126] = 2 × 3^2 × 5 × 7 = 630
EX: 一盒巧克力每 8 顆裝一袋會多 3 顆，每 12 顆裝一袋也多 3 顆。巧克力至少有幾顆（多於 3 顆）？
=> 巧克力數減去 3，是 8 和 12 的公倍數。
=> 最少是 [8, 12] + 3 = 24 + 3 = 27 顆

@+ 1-2-3
EX: 計算 1\f{2}{3} ÷ (−\f{5}{9})。
=> 化成假分數再乘倒數：\f{5}{3} × (−\f{9}{5})
=> = −3
EX: 計算 \f{1}{2} − \f{2}{3} × \f{9}{4}。
=> 先乘：\f{2}{3} × \f{9}{4} = \f{3}{2}
=> \f{1}{2} − \f{3}{2} = −1

@+ 1-2-4
EX: 計算 (2^3)^2 × 2^4 ÷ 2^7。
=> (2^3)^2 = 2^6
=> 2^{6 + 4 − 7} = 2^3 = 8
EX: 比較 2^{60} 與 3^{40} 的大小。
=> 2^{60} = (2^3)^{20} = 8^{20}，3^{40} = (3^2)^{20} = 9^{20}
=> 9 > 8，所以 3^{40} > 2^{60}

@+ 1-3-1
EX: 當 x = −3 時，求 \f{2x − 1}{7} + x 的值。
=> 2 × (−3) − 1 = −7，\f{−7}{7} = −1
=> −1 + (−3) = −4
EX: 化簡 \f{3x − 2}{4} − \f{x + 1}{2}。
=> 通分：\f{(3x − 2) − 2(x + 1)}{4}
=> = \f{3x − 2 − 2x − 2}{4} = \f{x − 4}{4}

@+ 1-3-2
EX: 解 3(2x − 5) = 4x + 7。
=> 去括號：6x − 15 = 4x + 7
=> 移項：2x = 22，x = 11
EX: 解 0.4x − 1.5 = 0.1x + 0.3。
=> 兩邊乘 10：4x − 15 = x + 3
=> 3x = 18，x = 6

@+ 1-3-3
EX: 甲、乙兩人從相距 18 公里的兩地同時出發、相向而行，甲每小時走 5 公里，乙每小時走 4 公里，幾小時後相遇？
=> 兩人每小時共靠近 5 + 4 = 9 公里。
=> 設 x 小時後相遇：9x = 18，x = 2
EX: 一件商品先打 8 折，再折價 30 元，結果賣 290 元，原價多少元？
=> 設原價 x 元：0.8x − 30 = 290
=> 0.8x = 320，x = 400
