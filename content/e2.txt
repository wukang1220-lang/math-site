@+ 2-1-1
EX: 求 3x + y = 10 的所有正整數解。
=> y = 10 − 3x 要大於 0，所以 x 只能是 1、2、3。
=> 解為 (1, 7)、(2, 4)、(3, 1)。
EX: 化簡 2(3x − y) − \f{4x − 6y}{2}。
=> \f{4x − 6y}{2} = 2x − 3y
=> 6x − 2y − (2x − 3y) = 6x − 2y − 2x + 3y = 4x + y

@+ 2-1-2
EX: 用代入消去法解 \sys{y = x + 2}{3x + 2y = 14}。
=> 代入：3x + 2(x + 2) = 14，5x = 10，x = 2
=> y = 2 + 2 = 4，解為 (2, 4)
EX: 解 \sys{2x + 3y = 13}{3x − 2y = 0}。
=> 第一式乘 2、第二式乘 3：4x + 6y = 26，9x − 6y = 0
=> 兩式相加：13x = 26，x = 2；代回得 y = 3

@+ 2-1-3
EX: 雞兔共 30 隻，腳共 84 隻，雞、兔各幾隻？
=> 設雞 x 隻、兔 y 隻：\sys{x + y = 30}{2x + 4y = 84}
=> 第二式除以 2 再減第一式：y = 12，x = 18
EX: 一艘船順流 2 小時行 36 公里，逆流 3 小時行 36 公里，求船在靜水中的速率與水流速率。
=> 順流速率 36 ÷ 2 = 18，逆流速率 36 ÷ 3 = 12：\sys{船速 + 水速 = 18}{船速 − 水速 = 12}
=> 船速每小時 15 公里，水速每小時 3 公里

@+ 2-2-1
EX: 點 P(2a − 4, a + 3) 在 x 軸上，求 P 的坐標。
=> x 軸上的點 y 坐標是 0：a + 3 = 0，a = −3
=> P(2 × (−3) − 4, 0) = P(−10, 0)
EX: 求 A(−2, 3)、B(4, 3)、C(4, −1) 三點圍成的三角形面積。
=> \seg{AB} 在水平線上，長 4 − (−2) = 6；\seg{BC} 在鉛直線上，長 3 − (−1) = 4。
=> 直角在 B，面積 = 6 × 4 ÷ 2 = 12

@+ 2-2-2
EX: 畫 2x + 3y = 6 的圖形，可以先找哪兩個點？
=> 令 x = 0：3y = 6，y = 2，得 (0, 2)
=> 令 y = 0：2x = 6，x = 3，得 (3, 0)；把兩點連成直線
EX: 求直線 x − y = 1 與 x + 2y = 7 的交點。
=> 交點就是聯立方程式的解：第二式減第一式，3y = 6，y = 2
=> x = 1 + 2 = 3，交點是 (3, 2)

@+ 2-3-1
EX: 把 1.2 : \f{4}{5} 化成最簡整數比。
=> 1.2 = \f{6}{5}，\f{6}{5} : \f{4}{5} 同乘 5 得 6 : 4
=> 再約分：3 : 2
EX: 若 x : y = 2 : 5，且 x + y = 35，求 x、y。
=> 設 x = 2r、y = 5r：7r = 35，r = 5
=> x = 10，y = 25

@+ 2-3-2
EX: y 與 x 成正比，x = 6 時 y = 15，求 x = 10 時的 y。
=> k = 15 ÷ 6 = \f{5}{2}，所以 y = \f{5}{2}x
=> x = 10 時，y = 25
EX: 從家到學校，騎車每分鐘 300 公尺要 8 分鐘；走路每分鐘 80 公尺，要幾分鐘？
=> 路程固定，速率與時間成反比：300 × 8 = 80 × t
=> t = 2400 ÷ 80 = 30 分鐘

@+ 2-4-1
EX: 用不等式表示「某數 x 的 4 倍減 3 大於 9」，並求出 x 的範圍。
=> 4x − 3 > 9
=> 4x > 12，x > 3
EX: 若 a > b，比較 3 − 2a 和 3 − 2b 的大小。
=> 兩邊乘 −2，方向改變：−2a < −2b
=> 兩邊加 3，方向不變：3 − 2a < 3 − 2b

@+ 2-4-2
EX: 解 \f{x + 3}{2} − 1 > \f{x}{3}。
=> 兩邊乘 6：3(x + 3) − 6 > 2x
=> 3x + 3 > 2x，x > −3
EX: 求同時滿足 3x − 2 ≥ 4 與 x − 7 < 1 的整數。
=> 第一式 x ≥ 2，第二式 x < 8
=> 重疊部分 2 ≤ x < 8，整數有 2、3、4、5、6、7

@+ 2-5-0
EX: 資料 12、15、15、18、20、24 中，把最大的 24 改成 60，平均數與中位數各有什麼變化？
=> 平均數由 104 ÷ 6 ≈ 17.3 變成 140 ÷ 6 ≈ 23.3，被極端值拉高。
=> 中位數仍是 (15 + 18) ÷ 2 = 16.5，沒有改變。
EX: 全班 40 人中，最喜歡籃球的有 14 人，畫成圓形圖時這一部分的圓心角是幾度？
=> 占全部的 \f{14}{40} = 35%
=> 圓心角 = 35% × 360° = 126°

@+ 2-6-0
EX: 正方形有幾條對稱軸？分別在哪裡？
=> 兩條對角線，以及連接兩組對邊中點的兩條直線。
=> 共 4 條。
EX: ∠AOB = 130°，射線 OC 是它的角平分線，射線 OD 是 ∠AOC 的角平分線，求 ∠AOD。
=> ∠AOC = 130° ÷ 2 = 65°
=> ∠AOD = 65° ÷ 2 = 32.5°
