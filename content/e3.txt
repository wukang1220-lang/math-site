// 第三冊新增例題（每單元補 2 題；皆為自編）

@+ 3-1-1
EX: 利用乘法公式計算 199^2。
=> 199^2 = (200 − 1)^2 = 40000 − 400 + 1
=> = 39601
EX: 已知 a + b = 5、ab = 3，求 (a − b)^2。
=> (a − b)^2 = (a + b)^2 − 4ab
=> = 25 − 12 = 13

@+ 3-1-2
EX: 把 4x − 7 + 2x^3 − x^2 依降冪排列，並寫出它的次數與常數項。
=> 降冪排列：2x^3 − x^2 + 4x − 7
=> 是三次多項式，常數項是 −7
EX: 若 A = 3x^2 − x + 2，B = x^2 + 4x − 5，求 2A − B。
=> 2A = 6x^2 − 2x + 4
=> 2A − B = 6x^2 − 2x + 4 − x^2 − 4x + 5 = 5x^2 − 6x + 9

@+ 3-1-3
EX: 展開 (x + 3)(x^2 − 2x + 1)。
=> = x^3 − 2x^2 + x + 3x^2 − 6x + 3
=> = x^3 + x^2 − 5x + 3
EX: 計算 (x^3 − 2x + 4) ÷ (x − 2)，求商式與餘式。
=> 被除式缺 x^2 項，補 0：x^3 + 0x^2 − 2x + 4
=> 商式 x^2 + 2x + 2；(x − 2)(x^2 + 2x + 2) = x^3 − 2x − 4，所以餘式是 8

@+ 3-2-1
EX: 求 0.81 的平方根，以及 \r{0.81} 的值。
=> 0.9^2 = 0.81，(−0.9)^2 = 0.81
=> 0.81 的平方根是 ±0.9，\r{0.81} = 0.9
EX: \r{55} 的整數部分是多少？
=> 7^2 = 49，8^2 = 64，49 < 55 < 64
=> 7 < \r{55} < 8，整數部分是 7

@+ 3-2-2
EX: 化簡 \f{\r{6}}{\r{3}} + \r{8}。
=> \f{\r{6}}{\r{3}} = \r{2}，\r{8} = 2\r{2}
=> \r{2} + 2\r{2} = 3\r{2}
EX: 把 \f{2}{\r{5} + \r{3}} 分母有理化。
=> 分子分母同乘 \r{5} − \r{3}：\f{2(\r{5} − \r{3})}{5 − 3}
=> = \r{5} − \r{3}

@+ 3-2-3
EX: 三邊長 9、40、41 的三角形是不是直角三角形？
=> 9^2 + 40^2 = 81 + 1600 = 1681
=> 41^2 = 1681，兩者相等，所以是直角三角形，41 所對的角是直角
EX: 求坐標平面上 A(−2, 1) 與 B(4, 9) 的距離。
=> 水平相差 6，鉛直相差 8
=> \seg{AB} = \r{6^2 + 8^2} = 10

@+ 3-3-1
EX: 因式分解 5x^2 − 20x。
=> 公因式是 5x
=> 5x^2 − 20x = 5x(x − 4)
EX: 因式分解 3x^2 − 12x + 12。
=> 先提出 3：3(x^2 − 4x + 4)
=> = 3(x − 2)^2

@+ 3-3-2
EX: 因式分解 x^2 − 3x − 28。
=> 找乘積 −28、和 −3 的兩數：−7 與 4
=> = (x − 7)(x + 4)
EX: 因式分解 4x^2 + 4x − 3。
=> 4 = 2 × 2，−3 = 3 × (−1)；交叉相乘 2 × (−1) + 3 × 2 = 4
=> = (2x + 3)(2x − 1)

@+ 3-4-1
EX: 解 x^2 − 16 = 0。
=> (x + 4)(x − 4) = 0
=> x = −4 或 x = 4
EX: 解 x(x + 2) = 15。
=> 先整理成右邊為 0：x^2 + 2x − 15 = 0
=> (x + 5)(x − 3) = 0，x = −5 或 x = 3

@+ 3-4-2
EX: 用配方法解 x^2 − 8x + 13 = 0。
=> x^2 − 8x + 16 = −13 + 16，(x − 4)^2 = 3
=> x = 4 ± \r{3}
EX: 判斷 2x^2 − 3x + 5 = 0 有沒有解。
=> 判別式 = (−3)^2 − 4 × 2 × 5 = 9 − 40 = −31
=> 小於 0，沒有解

@+ 3-4-3
EX: 兩個連續正整數的平方和是 145，求這兩個數。
=> n^2 + (n + 1)^2 = 145，整理得 n^2 + n − 72 = 0
=> (n + 9)(n − 8) = 0，n = 8，兩數是 8 和 9
EX: 某店的營業額兩年內由 100 萬元增加到 144 萬元，每年成長率相同，求成長率。
=> 100(1 + r)^2 = 144，(1 + r)^2 = 1.44
=> 1 + r = 1.2（−1.2 不合），成長率是 20%

@+ 3-5-0
EX: 某班 25 人身高分組：140~150 有 3 人、150~160 有 9 人、160~170 有 10 人、170~180 有 3 人。未滿 160 公分的累積相對次數是多少？
=> 未滿 160 公分的累積次數 = 3 + 9 = 12
=> 累積相對次數 = \f{12}{25} = 48%
EX: 60 筆資料中，某一組的相對次數是 15%，這一組有幾筆？
=> 次數 = 總數 × 相對次數
=> 60 × 15% = 9 筆
