// 第四冊新增例題（每單元補 2 題；皆為自編）

@+ 4-1-1
EX: 等差數列 7、11、15、… 的第 25 項是多少？
=> 公差 d = 4
=> a_{25} = 7 + 24 × 4 = 103
EX: 若 x、10、2x + 5 成等差數列，求 x。
=> 10 是等差中項：10 = \f{x + (2x + 5)}{2}
=> 3x + 5 = 20，x = 5（數列是 5、10、15）

@+ 4-1-2
EX: 求 2 + 5 + 8 + … + 59 的和。
=> 公差 3，項數 = \f{59 − 2}{3} + 1 = 20
=> 和 = \f{20 × (2 + 59)}{2} = 610
EX: 首項 3、公差 2 的等差級數，前幾項的和是 120？
=> S_n = \f{n[2 × 3 + (n − 1) × 2]}{2} = n(n + 2) = 120
=> n^2 + 2n − 120 = 0，(n + 12)(n − 10) = 0，n = 10

@+ 4-1-3
EX: 等比數列 81、27、9、… 的第 6 項是多少？
=> 公比 r = \f{1}{3}
=> a_6 = 81 × (\f{1}{3})^5 = \f{81}{243} = \f{1}{3}
EX: 等比數列的第 2 項是 6、第 5 項是 162，求公比與首項。
=> a_5 = a_2 × r^3：162 = 6r^3，r^3 = 27，r = 3
=> 首項 = 6 ÷ 3 = 2

@+ 4-2-0
EX: f(x) = 4x − 3，求 f(2) + f(−1)。
=> f(2) = 8 − 3 = 5，f(−1) = −4 − 3 = −7
=> f(2) + f(−1) = −2
EX: 手機月租 150 元，每分鐘通話 0.5 元。寫出月費 y 元與通話 x 分鐘的關係，並求通話 120 分鐘的月費。
=> y = 0.5x + 150
=> x = 120 時，y = 60 + 150 = 210 元

@+ 4-3-1
EX: △ABC 中 ∠C = 70°，∠A 比 ∠B 大 20°，求 ∠A。
=> ∠A + ∠B = 180° − 70° = 110°
=> ∠A = (110° + 20°) ÷ 2 = 65°
EX: 求正八邊形每個外角與每個內角的度數。
=> 每個外角 = 360° ÷ 8 = 45°
=> 每個內角 = 180° − 45° = 135°

@+ 4-3-2
EX: 說明如何只用尺規找出 \seg{AB} 的中點。
=> 分別以 A、B 為圓心、大於 \f{1}{2}\seg{AB} 的同一半徑畫弧，兩弧交於 P、Q。
=> 連 \seg{PQ}，它與 \seg{AB} 的交點就是中點。
EX: 怎樣只用尺規作出 22.5° 的角？
=> 過直線上一點作垂線得 90°，平分得 45°。
=> 再把 45° 平分一次，得 22.5°。

@+ 4-3-3
EX: \seg{AC} 與 \seg{BD} 交於 O，\seg{AO} = \seg{CO}、\seg{BO} = \seg{DO}，說明 \seg{AB} = \seg{CD}。
=> ∠AOB = ∠COD（對頂角），加上兩組邊相等，△AOB ≅ △COD（SAS）。
=> 對應邊相等，所以 \seg{AB} = \seg{CD}。
EX: △ABC 與 △DEF 中，∠A = ∠D = 40°，∠C = ∠F = 65°，\seg{AC} = \seg{DF} = 6，兩個三角形是否全等？
=> \seg{AC} 夾在 ∠A 與 ∠C 之間，\seg{DF} 夾在 ∠D 與 ∠F 之間。
=> 兩角及其夾邊對應相等，依 ASA 全等。

@+ 4-3-4
EX: P 在 \seg{AB} 的中垂線上，\seg{PA} = 2x + 3，\seg{PB} = 5x − 9，求 \seg{PA}。
=> 中垂線上的點到兩端點等距：2x + 3 = 5x − 9，x = 4
=> \seg{PA} = 2 × 4 + 3 = 11
EX: 直角三角形 ABC 中 ∠C = 90°、∠A = 30°，M 是斜邊 \seg{AB} 的中點，\seg{AB} = 12，求 \seg{CM} 與 \seg{BC}。
=> 斜邊中點到三頂點等距：\seg{CM} = \seg{BM} = 6
=> △BCM 中 \seg{BM} = \seg{CM}、∠B = 60°，是正三角形，所以 \seg{BC} = 6

@+ 4-3-5
EX: 3、5、9 能不能作為三角形的三邊長？
=> 兩短邊的和 3 + 5 = 8
=> 8 < 9，不能構成三角形
EX: △ABC 中 ∠A = 70°、∠B = 45°，把三邊依長短排列。
=> ∠C = 180° − 70° − 45° = 65°，所以 ∠A > ∠C > ∠B
=> 大角對大邊：\seg{BC} > \seg{AB} > \seg{AC}

@+ 4-4-1
EX: L_1 ∥ L_2，被截線所截的一組同位角是 (2x + 15)° 與 (4x − 25)°，求 x。
=> 同位角相等：2x + 15 = 4x − 25
=> x = 20，兩角都是 55°
EX: 兩條直線被一條截線所截，一組同側內角分別是 105° 與 75°，這兩條直線平行嗎？
=> 105° + 75° = 180°，同側內角互補。
=> 所以這兩條直線平行。

@+ 4-4-2
EX: 平行四邊形 ABCD 的周長是 36，\seg{AB} 比 \seg{BC} 長 4，求 \seg{AB}。
=> 對邊等長，\seg{AB} + \seg{BC} = 18，又 \seg{AB} − \seg{BC} = 4
=> \seg{AB} = (18 + 4) ÷ 2 = 11
EX: 平行四邊形 ABCD 的對角線交於 O，\seg{AC} = 14、\seg{BD} = 10、\seg{AB} = 8，求 △AOB 的周長。
=> 對角線互相平分：\seg{AO} = 7，\seg{BO} = 5
=> 周長 = 7 + 5 + 8 = 20

@+ 4-4-3
EX: 梯形的上底 8、下底 14、高 5，求中線長與面積。
=> 中線 = (8 + 14) ÷ 2 = 11
=> 面積 = (8 + 14) × 5 ÷ 2 = 55（也就是中線 × 高）
EX: 長方形 ABCD 的對角線交於 O，∠AOB = 60°，\seg{AC} = 10，求 \seg{AB}。
=> 對角線等長且互相平分：\seg{AO} = \seg{BO} = 5
=> △AOB 是頂角 60° 的等腰三角形，也就是正三角形，\seg{AB} = 5
