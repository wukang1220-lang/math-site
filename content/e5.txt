// 第五冊新增例題（每單元補 2 題；皆為自編）

@+ 5-1-1
EX: 把 0.5 : \f{2}{3} : 1.5 化成最簡整數比。
=> 寫成分數：\f{1}{2} : \f{2}{3} : \f{3}{2}，各項同乘 6
=> 得 3 : 4 : 9
EX: 三角形三內角的比是 1 : 3 : 5，求最大的角。
=> 最大角占全部的 \f{5}{1 + 3 + 5} = \f{5}{9}
=> 180° × \f{5}{9} = 100°

@+ 5-1-2
EX: △ABC 中 \seg{DE} ∥ \seg{BC}（D 在 \seg{AB} 上，E 在 \seg{AC} 上），\seg{AE} = 6、\seg{EC} = 3、\seg{AB} = 12，求 \seg{AD}。
=> \seg{AD} : \seg{AB} = \seg{AE} : \seg{AC} = 6 : 9
=> \seg{AD} = 12 × \f{6}{9} = 8
EX: △ABC 中 D 在 \seg{BC} 上，\seg{BD} : \seg{DC} = 3 : 5，△ABC 的面積是 48，求 △ABD 的面積。
=> △ABD 與 △ADC 等高，面積比等於底的比 3 : 5
=> △ABD = 48 × \f{3}{8} = 18

@+ 5-1-3
EX: △ABC ∼ △DEF，相似比是 2 : 3，△ABC 的周長是 18，求 △DEF 的周長。
=> 周長比等於相似比 2 : 3
=> △DEF 的周長 = 18 × \f{3}{2} = 27
EX: 三邊長 4、6、8 與 6、9、12 的兩個三角形是否相似？
=> \f{4}{6} = \f{6}{9} = \f{8}{12} = \f{2}{3}
=> 三組對應邊成比例，依 SSS 相似

@+ 5-1-4
EX: 直角三角形 ABC 中 ∠C = 90°，\seg{AB} = 13，\seg{BC} = 5，求 ∠A 的三個邊長比值。
=> \seg{AC} = \r{13^2 − 5^2} = 12
=> 對邊 : 斜邊 = \f{5}{13}（sin A），鄰邊 : 斜邊 = \f{12}{13}（cos A），對邊 : 鄰邊 = \f{5}{12}（tan A）
EX: 等腰直角三角形的斜邊長 8，求一股的長。
=> 邊長比 1 : 1 : \r{2}
=> 股 = \f{8}{\r{2}} = 4\r{2}

@+ 5-2-1
EX: 半徑 10、圓心角 72° 的扇形，求弧長與面積。
=> 弧長 = 2π × 10 × \f{72}{360} = 4π
=> 面積 = 100π × \f{72}{360} = 20π
EX: P 在圓 O 外，\seg{OP} = 10，半徑 6，從 P 作切線切圓於 T，求切線段 \seg{PT}。
=> 切線與半徑垂直，△OTP 是直角三角形，斜邊是 \seg{OP}
=> \seg{PT} = \r{10^2 − 6^2} = 8

@+ 5-2-2
EX: 圓內接四邊形 ABCD 中 ∠A = 2∠C，求 ∠A。
=> 對角互補：∠A + ∠C = 180°，3∠C = 180°
=> ∠C = 60°，∠A = 120°
EX: \seg{AB} 是圓的直徑，C 是圓上另一點，∠CAB = 28°，求 ∠ABC。
=> 直徑所對的圓周角 ∠ACB = 90°
=> ∠ABC = 180° − 90° − 28° = 62°

@+ 5-3-1
EX: 證明：等腰三角形 ABC 中 \seg{AB} = \seg{AC}，則 ∠B = ∠C。
=> 作 ∠A 的角平分線交 \seg{BC} 於 D：\seg{AB} = \seg{AC}（已知）、∠BAD = ∠CAD（角平分線）、\seg{AD} = \seg{AD}（公共邊）
=> 所以 △ABD ≅ △ACD（SAS），對應角 ∠B = ∠C
EX: 舉一個反例，說明「兩個奇數的和一定是奇數」是錯的。
=> 取 1 和 3，兩數都是奇數
=> 1 + 3 = 4 是偶數，所以這個敘述是錯的

@+ 5-3-2
EX: △ABC 中 ∠A = 64°，I 是內心，求 ∠BIC。
=> ∠BIC = 90° + \f{1}{2}∠A
=> = 90° + 32° = 122°
EX: G 是 △ABC 的重心，D 是 \seg{BC} 的中點，\seg{AD} = 15，△ABC 的面積是 60，求 \seg{AG} 與 △GBC 的面積。
=> \seg{AG} : \seg{GD} = 2 : 1，\seg{AG} = 15 × \f{2}{3} = 10
=> 重心與三頂點連線分成三個等面積的三角形，△GBC = 60 ÷ 3 = 20
