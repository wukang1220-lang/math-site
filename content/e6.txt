@+ 6-1-1
EX: 寫出 y = −\f{1}{2}(x + 4)^2 + 3 的頂點、對稱軸與開口方向。
=> 頂點 (−4, 3)，對稱軸 x = −4
=> a = −\f{1}{2} < 0，開口向下
EX: y = a(x − 1)^2 − 2 的圖形通過點 (3, 6)，求 a。
=> 代入：6 = a × (3 − 1)^2 − 2
=> 4a = 8，a = 2

@+ 6-1-2
EX: 求 y = 3(x + 1)^2 − 7 的最小值，以及此時的 x。
=> a = 3 > 0，開口向上，頂點 (−1, −7) 是最低點
=> x = −1 時有最小值 −7
EX: 球拋出後 t 秒的高度 h = −5(t − 1.5)^2 + 11.25（公尺），幾秒時最高？最高是幾公尺？
=> 開口向下，頂點是 (1.5, 11.25)
=> 1.5 秒時最高，高度 11.25 公尺

@+ 6-2-1
EX: 求資料 12、15、17、20、22、25、30 的全距與四分位距。
=> 全距 = 30 − 12 = 18
=> 中位數是 20；前半段 12、15、17 的中位數 Q_1 = 15，後半段 22、25、30 的中位數 Q_3 = 25，四分位距 = 10
EX: 某盒狀圖的最小值 30、Q_1 = 52、Q_2 = 60、Q_3 = 71、最大值 95，大約有多少比例的資料在 60 分以上？
=> Q_2 就是中位數 60
=> 大約一半（50%）的資料在 60 分以上

@+ 6-2-2
EX: 擲一顆公正的骰子，出現的點數是 3 的倍數的機率是多少？
=> 3 的倍數有 3、6 兩種
=> 機率 = \f{2}{6} = \f{1}{3}
EX: 同時擲兩枚公正的硬幣，用樹狀圖求「一正一反」的機率。
=> 第一枚有正、反，每一種再分出第二枚的正、反，共 4 種機會相等的結果
=> 一正一反有（正, 反）、（反, 正）2 種，機率 \f{2}{4} = \f{1}{2}

@+ 6-3-1
EX: 邊長 5 的正方體，求表面積與體積。
=> 表面積 = 6 × 5^2 = 150
=> 體積 = 5^3 = 125
EX: 底面半徑 4、高 10 的直圓柱，求側面積與表面積。
=> 側面積 = 2π × 4 × 10 = 80π
=> 表面積 = 2 × π × 4^2 + 80π = 32π + 80π = 112π

@+ 6-3-2
EX: 正四角錐的底面邊長 8、斜高 5，求表面積。
=> 底面積 64，每個側面 8 × 5 ÷ 2 = 20
=> 表面積 = 64 + 4 × 20 = 144
EX: 直圓錐的側面展開是圓心角 90° 的扇形，母線長 12，求底面半徑與側面積。
=> 360° × \f{r}{12} = 90°，r = 3
=> 側面積 = π × 3 × 12 = 36π
